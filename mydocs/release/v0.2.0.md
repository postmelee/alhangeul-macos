## GitHub Release 본문 구조 후보

### 변경 요약

- HWP/HWPX 문서를 파일명뿐 아니라 본문 단어로 찾을 수 있도록 macOS Spotlight 검색을 추가했습니다.
- 새 문서를 편집한 뒤 처음 저장할 때 잘못 표시되던 “저장할 문서가 없습니다” 오류를 수정했습니다.
- Word(.doc)·HTML 내보내기의 저장 창과 일부 문서의 미리보기 머리말·꼬리말 표시를 보완했습니다.

### 포함된 rhwp 변화

문서 처리 엔진과 편집 화면은 직전 공개 버전과 같은 [rhwp v0.8.6](https://github.com/edwardkim/rhwp/releases/tag/v0.8.6)을 사용합니다. 이번 버전에는 새 upstream 업데이트를 포함하지 않습니다.

### 알한글 앱 변화

- 앱을 설치하고 한 번 실행하면 기존 평문 HWP3/HWP5/HWPX의 본문 검색을 준비합니다. macOS의 색인 상태에 따라 결과가 나타나기까지 시간이 걸릴 수 있습니다. 암호·DRM·배포용 문서, 이미지 OCR과 일부 문서 요소는 검색 대상이 아닙니다.
- 새 문서의 첫 저장과 후속 저장, 미저장 상태 및 닫기 동작을 보정했습니다.
- Word(.doc)와 HTML 내보내기에서 macOS 저장 창을 표시하고, 내보내기 후 원래 문서의 저장 위치와 편집 상태를 유지합니다. Word 내보내기는 HTML 기반 .doc이며 모든 Word 버전에서의 배치 호환을 보장하지 않습니다.
- 일부 문서의 머리말·꼬리말 텍스트가 native 미리보기에서 누락되던 해석 경로를 보완했습니다. 앱과 Finder 미리보기의 모든 배치가 같아진다는 의미는 아닙니다.

## 지원 범위와 알려진 제한

- 평문 HWP3/HWP5/HWPX의 저장된 텍스트를 추출한다. 암호·DRM·배포용 및 손상/미지원 파일의 본문은 제공하지 않는다.
- 32 MiB 입력, 1 MiB UTF-8 출력, 200,000개 방문 단위·깊이 64 한도를 적용한다. 뒤쪽 본문은 빠질 수 있다. parser/압축 해제의 전체 CPU·메모리 상한을 보장하지 않는다.
- 이미지·스캔 OCR, 메모·숨은 설명 전용 데이터·바탕쪽, 그림/차트/OLE 내부 문서와 외부 자원은 제외한다. 가시성 필터는 아니다.
- importer는 로컬 본문을 macOS Spotlight 색인에 전달한다. importer 자체의 본문 네트워크 전송·별도 앱 색인·본문 로그는 없다.
- 문서 수정/보호/삭제 및 앱 제거가 기존 검색 단어를 즉시 제거한다고 보장하지 않는다. 실제 색인 전파와 검색 제외 설정에 영향을 받는다.
- 상세 범위는 [사용자 안내](../manual/spotlight_search_guide.md)와 [추출 계약](../tech/spotlight_text_extraction_contract.md)을 따른다.

출시 전에 다음을 완료하거나 미실행 항목에 대한 명시적인 출시 판단을 기록한다. **개발 후보의 실제 검색 성공을 공개 최초 설치와 출시 검증 완료로 간주하지 않는다.**

1. 개발 후보에서 확인한 txt 대조·한글/영문 본문 검색·수정/보호/삭제 전파를 최종 공개 후보에서도 재현한다.
2. 일반 설치/첫 실행 및 새 버전 교체에서 importer가 발견되는지 확인한다. 개발 등록을 필요로 했다면 공개 설치 성공과 구분한다.
3. 최소 지원 macOS 12와 Intel runtime 결과를 확보하거나, 검증 환경 부재에 대한 출시 판단을 남긴다. 최신 SDK의 min target 검사는 대체 증거가 아니다.
4. 실제 candidate/version/build와 포함 PR을 확정하고, 공증 DMG·내부 importer 서명·일반 설치·Finder/Thumbnail을 검증한다.
5. 공개 업데이트 실행 시 기존 설치본에서 Sparkle 업데이트 후 새 importer 발견·재색인과 기존 Preview/Thumbnail을 확인한다.
6. 최종 검증 결과로 공개 본문·README·Pages·appcast·Homebrew를 갱신한다. GitHub 첫 화면의 README는 기본 브랜치 main을 따르므로 devel의 문구는 승인된 릴리스 main 반영 시점에 공개 기준으로 확정한다. 준비 PR은 내부 기록과 Pages source만 준비한다. 공개 asset gate가 draft/prerelease를 거부하므로 후보 문구는 DMG 공개 전 배포하지 않는다. README/Cask는 현재 공개 v0.1.11을 유지하고 공개 후 별도 종료 정리로 정렬한다.

## 다운로드·배포 인계

비공개 공증 DMG와 checksum은 확보했고 공개 다운로드는 아직 없다. 양 아키텍처 최초 설치 → 로컬 GUI/Finder → 최종 승인 → 동일 DMG 승격 → 실제 Sparkle 업데이트/검색 순서로 #520 에서 진행한다. [현재 공개 릴리스](https://github.com/postmelee/alhangeul-macos/releases/tag/v0.1.11)를 유지한다. 공개 실행은 [릴리스 runbook](../manual/public_release_runbook.md)과 [Spotlight smoke](../manual/build_run_guide.md#spotlight-설치색인-smoke)를 따른다. 이 문서/PR만으로 배포 작업을 시작하지 않는다.
