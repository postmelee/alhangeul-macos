## 이번 버전의 주요 변경 사항 — 공개 문구 후보

아래 문구는 실제 검색 및 배포 검증을 마친 뒤 확정한다. 현재 공개 안내에 완료 기능처럼 복사하지 않는다.

### 변경 요약

- 평문 HWP3/HWP5/HWPX 문서를 본문 단어로 찾을 수 있도록 macOS Spotlight 연동을 추가하는 것이 목표다.
- 표·글상자·머리말·각주 등에 저장된 텍스트를 추출하고, 암호·DRM·배포용 문서와 이미지 OCR은 검색 대상에서 제외한다.
- native render tree의 큰 unsigned metadata 값을 보존하여 일부 문서의 머리말·꼬리말 text가 누락되던 decode 경로를 보완했다.

### 포함된 rhwp 변화

이번 Spotlight 작업은 현재 고정된 rhwp v0.8.6의 parser/model을 사용한다. 새 upstream 버전 반영은 포함하지 않는다. 실제 릴리스 시 core·Studio·lock/manifest 및 최신 upstream 반영 여부를 다시 확정한다.

### 알한글 앱 변화

Spotlight가 호출하는 앱 내 importer와 UTF-8 본문 추출 ABI를 추가했다. 앱 화면을 열지 않고도 로컬 파일에서 본문을 추출할 수 있다. 실제 본문 검색은 아직 정상 색인 환경의 검증이 필요하다.

추출 대상은 저장 모델의 문단·표/중첩 표·글상자·캡션·머리말/꼬리말·각주/미주·수식 script·양식 text다. 시각적 읽기 순서나 모든 자동 field를 재현하지 않는다. 스타일로 가린 일반 본문도 포함될 수 있어 기밀 제거 도구로 사용할 수 없다.

## 지원 범위와 알려진 제한

- 평문 HWP3/HWP5/HWPX의 저장된 텍스트를 추출한다. 암호·DRM·배포용 및 손상/미지원 파일의 본문은 제공하지 않는다.
- 32 MiB 입력, 1 MiB UTF-8 출력, 200,000개 방문 단위·깊이 64 한도를 적용한다. 뒤쪽 본문은 빠질 수 있다. parser/압축 해제의 전체 CPU·메모리 상한을 보장하지 않는다.
- 이미지·스캔 OCR, 메모·숨은 설명 전용 데이터·바탕쪽, 그림/차트/OLE 내부 문서와 외부 자원은 제외한다. 가시성 필터는 아니다.
- importer는 로컬 본문을 macOS Spotlight 색인에 전달한다. importer 자체의 본문 네트워크 전송·별도 앱 색인·본문 로그는 없다.
- 문서 수정/보호/삭제 및 앱 제거가 기존 검색 단어를 즉시 제거한다고 보장하지 않는다. 실제 색인 전파와 검색 제외 설정에 영향을 받는다.
- 상세 범위는 [사용자 안내](../manual/spotlight_search_guide.md)와 [추출 계약](../tech/spotlight_text_extraction_contract.md)을 따른다.

## 현재 검증과 출시 전 관문

2026-09-07, macOS 26.5.2 / Xcode 26.6 / Apple Silicon의 개발 패키지 기준이다. 아래 OK는 공개 DMG나 최소 OS 검증을 대신하지 않는다.

| 검증 | 상태 |
|---|---|
| Rust ABI·한도·수명 및 기존 native/golden 회귀 | OK |
| Debug/Release·4개 universal 실행 파일·bundle/UTI/서명 경로 | OK |
| 실제 mdimport HWP3/HWP5/HWPX 본문 | OK — 개발 등록 후 선택 경로 확인 |
| 수정/암호/빈/손상/DRM/배포용/입력·출력 한도 metadata | OK |
| 동일 버전 로컬 앱 교체·timestamp·첫 실행 재발견·미실행 추출 | OK |
| 시험 앱·문서·등록 정리와 기존 앱/provider 보존 | OK |
| 일반 txt의 실제 색인 대조 | FAIL — Data 볼륨 상태 unknown, 제한 대기 후에도 0건 |
| 실제 본문 검색·수정/보호/삭제 전파·Finder 양성 화면 | MISS — 정상 색인 환경에서 재검증 필요 |
| 깨끗한 환경의 일반 최초 설치 | MISS — 초기 발견 실패, 개발 등록 사용과 구분 |
| 전체 Quick Look 등록 위생 | MISS — 기존 두 설치본·과거 개발 레코드 보존 |
| macOS 12 및 Intel 실제 실행 | MISS — 환경 없음 / 미실행 |
| Developer ID·공증·Gatekeeper·공개 Sparkle 업데이트 | MISS — 릴리스 실행 범위에서 확인 |

출시 전에 다음을 완료하거나 미실행 항목에 대한 명시적인 출시 판단을 기록한다. **실제 본문 검색이 확인되지 않은 현재 상태를 기능 출시 검증 완료로 간주하지 않는다.**

1. 정상 색인 환경에서 txt 대조, 파일명에 없는 한글/영문 본문 검색, 대조군 제외, 문서 수정·보호·삭제의 이전 단어 제거를 확인한다.
2. 일반 설치/첫 실행 및 새 버전 교체에서 importer가 발견되는지 확인한다. 개발 등록을 필요로 했다면 공개 설치 성공과 구분한다.
3. 최소 지원 macOS 12와 Intel runtime 결과를 확보하거나, 검증 환경 부재에 대한 출시 판단을 남긴다. 최신 SDK의 min target 검사는 대체 증거가 아니다.
4. 실제 candidate/version/build와 포함 PR을 확정하고, 공증 DMG·내부 importer 서명·일반 설치·Finder/Thumbnail을 검증한다.
5. 공개 업데이트 실행 시 기존 설치본에서 Sparkle 업데이트 후 새 importer 발견·재색인과 기존 Preview/Thumbnail을 확인한다.
6. 최종 검증 결과로 공개 본문·README·Pages·appcast·Homebrew를 갱신한다. 현재는 이 공개 자산들을 수정하지 않는다.
