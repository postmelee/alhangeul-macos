## GitHub Release 본문 구조 후보

### 변경 요약

- 같은 버전의 알한글을 삭제한 뒤 다시 설치했을 때, 기존 한글 문서의 Spotlight 검색 준비가 생략될 수 있던 문제를 보완했습니다.

### 포함된 rhwp 변화

문서 처리 엔진과 편집 화면은 직전 공개 버전과 같은 [rhwp v0.8.6](https://github.com/edwardkim/rhwp/releases/tag/v0.8.6)을 사용합니다. 이번 패치는 새 upstream 업데이트를 포함하지 않습니다.

### 알한글 앱 변화

- 같은 버전 앱을 같은 위치에 다시 설치해도 새 설치로 인식하여 기존 평문 HWP3/HWP5/HWPX 문서의 검색 준비를 다시 요청합니다.
- 기존 설정을 초기화할 필요가 없으며 일반적인 앱 재실행에서는 같은 요청을 반복하지 않습니다.
- 설치 후 한 번 실행하고 앱을 켜 둔 채 잠시 기다려 주세요. macOS의 색인 상태와 문서 수에 따라 결과가 반영되기까지 시간이 걸릴 수 있습니다. 색인된 문서는 앱 종료 후에도 검색할 수 있습니다.

## 지원 범위와 알려진 한계

- macOS 12 이상을 대상으로 빌드하며 최소 OS 실기기 환경은 없어 실행 검증하지 못했다. 새 VM 양 아키텍처와 현재 Mac 결과를 최소 OS 성공으로 확대하지 않는다.
- 검색은 저장된 평문 텍스트를 대상으로 한다. 암호·DRM·배포용 문서, 이미지/스캔 OCR과 일부 문서 요소는 제외한다. 입력/출력 한도로 긴 문서 뒤쪽이 빠질 수 있다.
- 색인 등록·수정·삭제 반영은 비동기이며 즉시 검색을 보장하지 않는다. [검색 안내](../manual/spotlight_search_guide.md)를 따른다.
- `저장하지 않음`으로 닫은 문서가 다음 실행의 복구 목록에 남는 #525 는 이번 패치에 포함되지 않는다. 기존 저장 파일 보존과 구분해 남은 한계로 기록한다.
- 실제 VM/현재 Mac 수용은 아래 표에 새 후보 증거로 기록한다. 이전 개발 후보나 v0.2.0의 PASS를 재사용하지 않는다.
