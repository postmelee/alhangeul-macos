## 사용자용 요약

`v0.1.10`은 HWP/HWPX 형식별 native 저장과 재열기, 현재 편집 상태의 전체 페이지 PDF·인쇄, 해당 offscreen renderer의 WebKit 보안 경계와 `rhwp v0.8.4` 문서 호환성 개선을 묶는 patch release다.

- HWP와 HWPX를 선택한 형식 그대로 저장하고 저장 결과를 다시 열 수 있다.
- HWPX 저장 뒤 후속 `Command+S`도 같은 URL과 HWPX 형식을 유지한다.
- 현재 편집 상태의 모든 page SVG를 searchable PDF와 native print flow에서 공유한다.
- 문서 유래 SVG의 script, 외부 resource와 navigation을 PDF·인쇄 전용 WebView에서 차단한다.
- `rhwp v0.8.4` 누적 변화로 암호 문서, 중첩 표 조판·선택·복사, PUA 글리프와 대형 문서 처리 범위를 보강한다.
- v0.8.4 render tree schema를 Swift decoder가 수용해 native Quick Look/Thumbnail 경로의 호환성을 유지한다.
- 영구 사용자·기기·설치 식별자 없는 익명 실행·업데이트 추이를 개인정보 설정에서 끌 수 있다.

## GitHub Release 본문 구조 후보

### 변경 요약

- HWP와 HWPX를 형식에 맞는 macOS 저장 패널로 저장하고, 저장 결과를 같은 형식으로 다시 열 수 있습니다.
- 현재 편집 상태의 전체 페이지를 searchable PDF로 저장하고 같은 page geometry로 native 인쇄를 시작합니다.
- PDF·인쇄용 문서 SVG의 script, 외부 resource와 navigation을 전용 WebView에서 차단합니다.
- `rhwp v0.8.4`를 반영해 암호 문서, 중첩 표, 특수 글리프와 대형 문서 처리 범위를 보강했습니다.
- 개인정보 설정에서 영구 사용자·기기 식별자 없는 익명 실행·업데이트 추이 공유를 끌 수 있습니다.

### 포함된 rhwp 변화

- core와 bundled `rhwp-studio`는 [`rhwp v0.8.4`](https://github.com/edwardkim/rhwp/releases/tag/v0.8.4), commit `496333b27d21ddb9114ba9ae340bcb895870c9a7`을 함께 사용합니다.
- HWP5 EncryptVersion 4, HWP3와 암호화 HWPX의 열기·암호화 저장·재열기 계약을 확장했습니다.
- 중첩 표의 페이지 분할·셀 흐름·하단 테두리와 표 내부 선택·복사·서식·크기 조절을 개선했습니다.
- PUA로 기록된 사각 번호와 작은 오른쪽 삼각형을 실제 글리프로 복원합니다.
- 압축 해제 상한과 대형 표 편집·렌더링 개선으로 비정상 입력과 큰 문서 처리 위험을 줄였습니다.
- v0.8.4는 v0.8.3에서 의도치 않게 활성화된 배포 채널을 철회한 patch이며, 알한글에 포함되는 core/studio 문서 기능은 같은 v0.8.4 provenance로 고정했습니다.

### 알한글 앱 변화

- HWP/HWPX 저장 command부터 exporter response, 목적지 확장자와 CFB/ZIP signature까지 같은 형식 계약을 사용합니다.
- HWPX 저장 뒤 후속 `Command+S`도 같은 URL과 HWPX 형식을 유지합니다.
- PDF 저장과 인쇄는 현재 editor의 page SVG를 공용 renderer로 변환해 최신 편집 내용, page geometry와 searchable text를 반영합니다.
- PDF·인쇄 renderer는 content JavaScript와 popup을 끄고 inline style과 embedded `data:` image 외 resource·navigation을 기본 차단합니다.
- `rhwp v0.8.4`에서 제거된 render-tree field와 기존 JSON을 모두 수용해 native Quick Look/Thumbnail 호환성을 유지합니다.
- 익명 실행·업데이트 이벤트는 문서 내용·파일명·경로나 영구 식별자를 포함하지 않으며, opt-out하면 보관 중인 이벤트를 삭제합니다.
- 앱, Quick Look과 Thumbnail extension의 version/build는 모두 `0.1.10 (16)`입니다.

### 기술 세부

- PR #464는 complete `rhwp-core.lock`에서 canonical `RhwpCoreBuildInfo.swift`를 생성하는 sync writer와 verifier를 분리한다. 일반 PR/release는 writer를 실행하지 않고 mismatch를 차단한다.
- PR #465는 bundled studio manifest의 resolved commit과 `source_cargo_lock_sha256`을 target upstream checkout HEAD와 root `Cargo.lock` actual hash에 결합한다.
- PR #468은 사용하지 않는 `dirty` property/CodingKey만 제거하고 JSONDecoder의 unknown-key 허용으로 legacy JSON을 유지한다. current/legacy envelope와 전체 TextRun/TextStyle fixture를 PR CI에 추가했다.
- PR #471은 core lock, RustBridge dependency, generated build info와 bundled studio를 같은 `v0.8.4` commit으로 정렬했다.
- local v0.8.4 strict `librhwp.a` byte hash/size 차이는 lock 갱신 근거로 사용하지 않는다. Stage 3에서 strict와 portable source/header/FFI 결과를 분리한다.

## 알려진 제한 사항과 후속 이슈

- 앱 viewer/editor는 bundled `rhwp-studio` WKWebView 경로이고 Quick Look/Thumbnail은 Rust bridge와 Swift native renderer 경로다. 같은 문서도 일부 글꼴, 배치와 페이지 표현이 다를 수 있다.
- HWP/HWPX 저장은 대표 fixture의 container, text/nonblank render와 재열기를 확인했지만 upstream exporter의 모든 요소에 대한 의미론적 완전 무손실을 보장하지 않는다.
- HWPX runtime guard는 ZIP magic까지만 검사하며 손상 ZIP이나 필수 entry 누락의 완전한 container 검증은 별도 smoke에 의존한다.
- PDF 내보내기는 전체 page SVG 문자열을 bridge/native payload에 보유한다. page별 timeout은 있지만 document 전체 deadline, progress와 수집 중 취소 UI는 없다.
- 실제 가로·세로 혼합 HWP/HWPX fixture는 없다. 혼합 geometry와 print orientation 미강제는 합성 SVG 자동 테스트로 검증했다.
- PDF/인쇄 renderer의 `style-src 'unsafe-inline'`과 `img-src data:`는 현재 upstream SVG 충실도에 필요한 최소 예외다.
- 익명 실행 추이는 전체 설치 수나 고유 사용자 수가 아니라 network를 통해 endpoint에 도달한 event 수다. 영구 폐쇄망과 보관기간 내 재연결되지 않은 실행은 관측하지 않는다.
- deployment target macOS 12 실장과 Intel Mac 실제 설치·실행은 실행하지 않으면 통과로 기록하지 않는다.
- [#459](https://github.com/postmelee/alhangeul-macos/issues/459)는 PDF·인쇄 lifecycle의 중복/stale callback 후속이다.
- [#469](https://github.com/postmelee/alhangeul-macos/issues/469)는 producer-backed render-tree golden, [#470](https://github.com/postmelee/alhangeul-macos/issues/470)는 decoder 실패 진단 후속이다.
