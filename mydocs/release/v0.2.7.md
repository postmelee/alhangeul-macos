## GitHub Release 본문 구조 후보

### 변경 요약

- HWP·HWPX 편집 도구 막대의 그림 버튼을 눌러도 파일 선택창이 뜨지 않던 문제를 수정했습니다.

### 포함된 rhwp 변화

- 문서 엔진과 내장 편집기는 [rhwp v0.9.1](https://github.com/edwardkim/rhwp/releases/tag/v0.9.1)을 사용합니다.

### 알한글 앱 변화

- 그림 파일을 선택하거나 취소한 뒤 다시 시도할 수 있습니다. 삽입한 PNG·JPEG는 문서를 저장하고 재열기할 수 있습니다.

### 릴리즈 요약에 반영된 PR

- [#631: 그림 삽입 파일 선택창 복구](https://github.com/postmelee/alhangeul-macos/pull/631) - 편집기의 그림 파일 선택 요청을 macOS 파일 선택창에 연결합니다.
