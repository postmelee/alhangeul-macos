## 사용자 변화 초안 — 최종 DMG 수용 전

### 변경 요약

- Mac에 활성 설치된 글꼴을 설정에서 켜고 문서의 기존 글꼴 목록에서 선택하는 기능을 준비했습니다. 정상 읽기 권한에서는 재실행에도 사용 설정이 유지됩니다.
- 선택한 지원 글꼴을 문서 화면뿐 아니라 PDF·인쇄와 Finder 미리보기·썸네일에서 사용하도록 연결했습니다. 읽을 수 없거나 지원 범위를 벗어나면 정해진 안내·대체 동작을 따릅니다.
- 반복 Finder 요청의 글꼴 준비 재사용과 여러 파일 썸네일의 동시 대기를 개선했습니다. 모든 Mac의 지연 상한이나 앱 실행시간 개선율을 보장하지 않습니다.

### 포함된 rhwp 변화

직전 앱의 rhwp v0.8.6에서 공식 v0.8.7로 core와 Studio를 함께 갱신했다. 공식 릴리즈에서 표 너비·표의 쪽 나눔과 문단 배치, 일부 저장본 호환성, 하이퍼링크/편집 동작 및 문서 입력 경계 보완을 확인했다. 호스트 글꼴 공급 API는 알한글의 Mac 연결에 사용한다. 각 문서의 한컴 동일 표현이나 모든 문서 오류 해결을 보장하지 않으며, 실제 앱의 주요 경로는 새 DMG에서 다시 수용한다. 브라우저 스토어/CLI 패키지 배포를 알한글 기능으로 나열하지 않는다.

### 알한글 앱 변화

설정(⌘,) → 글꼴 → Mac에 설치된 글꼴 사용을 켠 뒤 기존 글꼴 목록의 시스템 글꼴에서 고른다. 기본은 OFF이며 정상 권한에서 감지·가져오기를 매번 다시 누르는 동선은 필요하지 않다. 상세 설정과 별도 가져온 복사본 보관은 구분하며 앱 Help의 Mac 글꼴 사용 안내로 연결한다.

### 릴리즈 요약·이슈의 후보

## 지원 범위와 수용 경계

Mac 기능은 활성 설치된 일반 TTF/OTF의 검증된 Regular/Bold를 중심으로 한다. 설치 원본의 존재·활성·권한이 필요하며 한컴 앱 내부 추출 또는 한컴 제거 후 모든 글꼴 유지를 보장하지 않는다. 별도 가져온 독립 복사본과 설치 참조를 구분한다. TTC 개별 face·가변 축·HFT·전체 complex shaping/쪽 배치·외부 사용 라이선스·모든 시스템 글꼴은 보장 범위 밖이다.

기존 #569 signed 진단 앱의 실제 NanumSquare·문서/PDF·인쇄 취소·Finder 수용과 #580 반복 metadata 약 160~170ms/provider 약 328~343ms 증거를 인계한다. 원래 <300ms 미충족과 다수 파일 첫 miss 지연은 유지한다. 이전 232 family/809 records는 그 Mac의 당시 관측이며 새 후보의 정답으로 고정하지 않는다.

최종 일반 Release·공증 DMG, 새 ARM/Intel VM 설치·재설치, 실제 Mac 및 v0.2.2 → v0.2.3 실제 Sparkle 업데이트는 미실행이다. 최소 macOS 12·Intel 실기기 GUI·실제 한컴 제거·물리 인쇄도 미검증이다. 기존 격리 앱, VM 검색 성공 또는 static universal slice 검사로 대체하지 않는다.
