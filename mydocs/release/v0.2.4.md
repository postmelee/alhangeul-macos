[PR #602](https://github.com/postmelee/alhangeul-macos/pull/602)의 최종 head는 `3c1e7b36bb3f060203532edc2fb1cb40b48e7cad`다. 로컬 리허설은 머지 커밋에서 패키징했다. 입력 앱은 `22717d83`에서 빌드해 검증한 Universal Release다. 두 커밋 사이의 변경은 진단 예제, 생명주기 테스트, 문서뿐이며 앱 실행 파일과 세 플러그인 해시, Studio 자산을 다시 대조했다. #601 작업 사본도 4단계에서 검증한 universal archive와 헤더에 맞췄다.

## GitHub Release 본문 구조 후보

### 변경 요약

- 편집 명령이 실패해도 문서 상태가 복구되면 같은 창에서 계속 편집할 수 있습니다.
- 딸기 Regular 글꼴을 가져오면 sample10 HWP3·HWPX 표지에 지정된 굵은 글자를 화면과 PDF에서 볼 수 있습니다.

### 포함된 rhwp 변화

문서 엔진과 내장 Studio를 공식 [rhwp v0.9.0](https://github.com/edwardkim/rhwp/releases/tag/v0.9.0)으로 갱신했습니다. 편집 오류의 복구 상태를 앱에 전달하고, 기본 글꼴 서버가 응답하지 않을 때도 대체 글꼴로 문서를 열 수 있습니다.

### 알한글 앱 변화

- 여러 구역에 걸친 선택을 삭제하면 내용과 선택을 보존하고 편집을 중단합니다. 삭제하려면 한 구역씩 선택해 주세요.
- 복구를 확인한 문서에서는 실행 취소·다시 실행과 저장을 이어갈 수 있습니다. 복구를 확인할 수 없으면 편집과 저장을 중단해 이전 저장본을 보호합니다. 오류 안내에서 상세 정보를 복사할 수 있습니다.
- HWPX가 조판을 시작하기 전에 앱에 가져온 HFT 대응 글꼴을 연결합니다. 딸기 Regular만 있는 경우에도 문서에 지정된 굵기를 PDF에 적용하고 글자를 한 번씩 검색·복사할 수 있습니다.

## 이전 후보의 리허설 DMG

제품 커밋 `7a0103a4`에서 빌드한 로컬 미서명 리허설은 `alhangeul-macos-0.2.4-rehearsal.dmg`, 347897131 bytes, SHA-256 `001850671499d1a05e8c6ad60adcc39381958067467bb555b090aeb7413d861b`다. 앱·Quick Look·Thumbnail·Spotlight는 모두 0.2.4 / 22 및 arm64/x86_64다. 앱 내 Studio 자산 전체와 네이티브 matcher receipt가 소스와 일치했다.

외장 디스크의 지정 mountpoint에서 권한 오류가 발생해 같은 Release 앱을 저장소의 staging·Finder 레이아웃 절차와 macOS 기본 mountpoint로 패키징했다. hdiutil verify와 SHA-256 검증을 통과했다. 압축된 DMG를 읽기 전용으로 열어 파일 SHA·실행 가능 여부·심볼릭 링크·디렉터리 총 285개를 빌드 앱과 대조했다. Applications 링크·배경·Finder 레이아웃 파일도 확인했다. 이 검사는 Intel 실기 실행이나 서명·공증 설치 수용을 포함하지 않는다.

제품 후보는 `22717d830efb0b8a72e6986e4d67711f1a7db8e3`이다. #601의 `33013d24`와 #600 글꼴 수정 `b7bba77d`가 함께 들어 있다. 공식 rhwp v0.9.0 pin을 유지한다. 이 후보의 Studio manifest SHA-256은 `ff3cd3090446c2bb78439bb388c15acce6884f1e4ef558b774cb5cd806203b6a`다.

동일 소스에서 sample10 HWP3·HWPX 첫 쪽의 딸기 화면·PDF·네이티브 출력, 고운바탕 저장·재열기, #594 복구 검사 일반 40건·CDN 무응답 44건, HostApp XCTest 265건이 통과했다. 미서명 Release 앱과 세 플러그인은 모두 0.2.4 / 22, arm64·x86_64다. 릴리스 패키징 시 이 제품 후보와 [4단계 보고서](../working/task_m020_600_stage4.md)의 자산 해시를 기준으로 삼는다. 위 리허설 DMG는 이전 제품 소스로 만들었다.

## 공개 전 확인 사항

제보 원본 문서에서의 타이핑 지연은 이번 복구·초기화 검사로 성능을 판정할 수 없다. 동일 HWPX의 Windows 한컴 출력과 비교하면 표지의 대상 글줄이 약 4pt 오른쪽에 놓인다. 같은 OTF를 고정한 rhwp 대조에서 저장된 줄에 그림 오른쪽 여백 8.52pt가 다시 적용돼 중심이 4.26pt 이동했다. 이 후보에는 해당 위치 보정이 없다. [공식 태그의 줄 배치 계산](https://github.com/edwardkim/rhwp/blob/c9095c5f67632e6721e800ccc7fb43ea49d26682/src/renderer/layout/paragraph_layout.rs#L7101)

공식 Studio 외부 글꼴 공급자는 화면에 그릴 face를 제공하며 Rust의 첫 조판은 계약 범위 밖이다. 이 HWPX에서 공식 호스트 공급 경로의 딸기 읽기는 0회였고, 알한글은 조판 전에 공급 가능한 원본을 연결했다. [공식 공급자 계약](https://github.com/edwardkim/rhwp/blob/c9095c5f67632e6721e800ccc7fb43ea49d26682/rhwp-studio/HOST_FONTS.md#L29-L57)

실제 Mac의 Finder·Spotlight 본문 검색은 #587에서 추적한다. v0.2.3 당시 실제 Mac은 일반 TXT 검색부터 재현이 일정하지 않았고, 당시 VM 결과와 실제 importer 추출을 대체 근거로 수용했다. v0.2.4 서명본은 설치 후 첫 검색, 앱 종료 후 검색, 재설치 및 실제 업데이트를 별도로 검증한다. 공개 승격에는 버전별 Pages 안내 파일도 필요하다.

공개 입력 후보는 직전 참조 v0.2.3, expected_rhwp_tag v0.9.0, require_latest_rhwp=true, 제목 Alhangeul v0.2.4, draft=true, prerelease=false다. 공개 기준 main 커밋 확정 후 동일한 서명·공증 DMG로 설치와 업데이트를 검증하고 공개 승인을 받는다.
