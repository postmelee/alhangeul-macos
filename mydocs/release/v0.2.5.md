실제 Mac Spotlight 본문 검색의 환경 차이는 [#587](https://github.com/postmelee/alhangeul-macos/issues/587)에서 추적한다. 새 후보의 실제 Mac 결과와 이전 버전의 예외 승인 근거를 구분한다.

## GitHub Release 본문 구조 후보

### 변경 요약

- 문서를 열었을 때 첫 페이지가 빈 화면으로 남는 문제를 개선했습니다.
- Finder에서 Polaris HWP 미리보기와 썸네일을 지원하며, 일부 OLE 차트가 자리표시자로만 보이던 빠른 보기를 개선했습니다.

### 포함된 rhwp 변화

문서 엔진과 내장 편집기를 공식 [rhwp v0.9.1](https://github.com/edwardkim/rhwp/releases/tag/v0.9.1)로 갱신했습니다.

### 알한글 앱 변화

- 앱에 가져온 글꼴을 처리하면서 문서가 준비되는 과정과 첫 페이지 표시를 개선했습니다.
- 로딩 중 다른 문서를 열면 새 문서를 표시하도록 준비 과정을 개선했습니다.
- Finder 빠른 보기에서 지원되는 OLE 차트의 막대, 축, 범례가 표시되도록 렌더링 경로를 보완했습니다.
