# Task M020 #513 구현계획서

## Stage 1: 기준 고정과 기존 실패 재현

선행 SHA·패키지 서명과 실행 파일 hash·fixture를 확인한다. 활성 smoke, 프로세스, importer/provider를 읽어 공유 시스템을 점검한다. 기존 표준 smoke의 prepare → environment → install → launch 결과와 elapsed time을 기록하고 실패 후에도 정리한다.

## Stage 2: 조건 분리와 검증 절차 보완

기존 helper의 수동 `lsregister -f`, `mdimport -i` 경로와 별개로 순수 복사/첫 실행/검색 경로를 만든다. 중첩 위치와 일반 Applications 바로 아래의 고유 소유 앱을 비교할 수 있도록 경로 소유권 검사를 유지한다. 복사 후 timestamp만 변경, 재등록만 수행, 첫 실행 순서/관찰 시간을 각각 기록한다. 기존 사용자 동일 ID 앱은 제거하지 않으므로 그 영향은 실험으로 확정할 수 없는 한 한계로 남긴다.

일반 설치 판정에서 수동 재색인·touch·강제 등록·재설치가 섞이면 통과를 거부하도록 회귀 검증한다. 제품 코드는 원인 근거가 있을 때만 최소 변경한다.

## Stage 3: 실제 결과와 후속 PR 준비

설치 전 corpus의 HWP3/HWP5/HWPX 영문 및 HWP5/HWPX 한글 독립 단어, 대조군 제외, 후보 선택, 앱 종료 후 검색을 확인한다. 같은 경로 교체와 수정/삭제 전파는 최초 설치와 구분한다. 실패·미실행은 그대로 기록하고 소유 시험 앱/문서/등록 제거와 기존 앱/provider 보존을 검증한다. 검증 명령·합성 공개 증거·보고서 및 PR 본문 초안을 준비한다.

## 검증

Python 운영/소유권 회귀, 변경 파일 구문 검사, `git diff --check`, 실제 macOS smoke. 패키지/앱 변경 시 build 가이드의 해당 최소 검증을 추가한다. 공개 서명/공증 및 없는 macOS 12/Intel 환경은 실행하지 않는다.
