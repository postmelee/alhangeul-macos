# #587 Spotlight 본문 검색 수행계획

공개 v0.2.7에서 Polaris HWP는 지원 UTI 누락으로 importer가 선택되지 않았다. HWPX는 설치된 importer가 본문을 반환했으나 실제 Mac에서 자동 본문 검색이 성공하지 않았다. [기존 관찰](https://github.com/postmelee/alhangeul-macos/issues/587#issuecomment-7091545111)

1. 공개판의 설치와 OS 상태를 확인하고 T7 새 합성 표본에서 자동 발견, importer 메타데이터, 본문 검색, 파일 단위 요청의 차이를 기록한다.
2. Polaris UTI를 importer와 schema에 연결한다. HWPX는 관찰에서 드러난 원인에 맞춰 제품이나 검증 도구의 필요한 부분을 수정한다.
3. 후보에서 Polaris HWP 추출과 HWP/HWPX의 본문 검색을 실제 Mac으로 검증하고, 자동 발생한 결과와 진단용 파일 단위 요청의 결과를 기록한다.
