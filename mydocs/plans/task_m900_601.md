# v0.2.4 릴리스 준비 수행계획

직전 공개판 v0.2.3 / build 21에서 공식 rhwp v0.9.0을 포함하는 v0.2.4 / build 22로 올린다. 작업지시자가 #600 후보와 #594 통합·검증, 릴리스 준비 및 버전을 승인했다.

1. #600 공식 자산과 #594 실제 복구 연동을 통합한 소스에서 앱·확장 네 곳의 버전과 워크플로 입력을 일치시킨다.
2. WKWebView에서 정상·웹폰트 무응답, HWP/HWPX 복구·저장·재열기, 복구할 수 없는 상태의 보호 분기를 확인한다. 실제 글꼴 검증은 #600 결과와 대조한다.
3. Universal Release와 로컬 리허설 DMG를 생성해 번들 버전·아키텍처·Studio 자산·디스크 이미지 무결성을 검증한다.
4. 릴리스 기록에 사용자 변화, 알려진 한계 및 #587 후속을 명시한다. 공개용 main 커밋 확정, 서명·공증과 설치 검증, 공개 승인은 public release runbook에 따른다.
