# #587 Spotlight 본문 검색 구현계획

1. 공개 설치본을 사용한다. T7의 새 폴더에 평문 HWP·HWPX와 같은 본문이 담긴 TXT를 만들고, 파일명에 없는 독립 영문·한글 단어를 조회한다. 시스템 로그, importer가 제공한 제목, test mode 메타데이터와 진단용 단일 파일 요청을 대조한다.
2. Polaris HWP 지원을 importer plist와 schema에 추가하고 계약 검사에 반영한다. HWPX에서 호출이 빠졌는지, 파일 읽기·추출이 실패했는지, 결과가 색인되지 않았는지 경계별로 확인해 수정 범위를 결정한다.
3. 후보의 bundle 계약과 직접 호출 회귀를 검사하고 동일 실기기에서 새 표본으로 자동 검색을 검증한다. 표준 설치 smoke에서 임시 등록을 사용한 경우 시험 후 원래 설치 상태를 대조한다.

검증 증거는 T7에 두고 추적 문서에 요약한다. 합성 표본과 작업 전용 설치본을 사용하며 시스템 전체 색인 설정을 바꾸지 않는다.
