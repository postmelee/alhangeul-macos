# Task M020 #469 수행계획서

## 목적과 범위

pinned core가 실제 생성한 render tree 전체 page를 deterministic golden으로 관리한다. source pin/sample/page와 golden의 관계를 검증하고 Swift decoder의 계약 이탈을 차단한다. minimal 수동 fixture는 유지한다.

대상은 저장소 `samples/basic/request.hwp`(64 KiB), page 0이다. 현재 출력은 약 208 KiB이며 TextRun/Table/Rectangle 등과 큰 unsigned marker를 포함한다. 새 Rust example은 기존 FFI와 같은 `DocumentCore::from_bytes → build_page_render_tree → tree.root` 경로를 사용한다. `cargo run --release --locked --target <host>`로 현재 Cargo pin을 실제 빌드하므로 stale Frameworks에 의존하지 않는다.

Writer는 full sync에서 complete core build 후 명시 실행한다. 일반 PR/release는 verifier만 실행한다. 두 경로는 별도 명령이며 build-info writer와 책임을 섞지 않는다. canonical JSON은 key 정렬·공백만 정규화하고 필드/배열 순서/숫자/문자열을 보존한다. 비결정적 필드가 발견되면 원인 조사 후 정책을 확정한다.

#470 PR #504 head `d527be8`를 상속한다. 사용자의 단계 승인 생략 및 PR 게시 지시에 따라 진행한다. core pin 변경·public release·전체 node/pixel coverage는 제외한다.
