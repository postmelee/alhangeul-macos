# Task M900 #621 수행계획서

[릴리즈 운영 이슈 #621](https://github.com/postmelee/alhangeul-macos/issues/621) · 2026-11-20

v0.2.4/22를 직전 공개판으로 두고 공식 rhwp v0.9.1을 포함한 v0.2.5/23을 검증해 배포한다. #611 Polaris, #613 OLE, #616 최초 표시 및 #618 공식 동기화에 대해 실행 근거를 남긴다. 메모 기능은 이번 후보에서 제외한다.

1. 동기화 workflow와 생성된 후보 PR의 CI를 확인하고 `devel`에서 core와 Studio 출처를 고정한다.
2. 동일 후보에서 WKWebView 문서 사용, Finder 확장 및 미해결 제보를 검증한다. 릴리즈 소스를 `main`에 통합하고 서명·공증한 하나의 DMG로 실제 Mac과 ARM·Intel VM의 최초 설치 및 재설치를 확인한다.
3. 검증한 동일 DMG를 공개한다. Pages, Sparkle 업데이트, Homebrew 업그레이드·설치를 확인하고 배포 기록과 외부 제보 이슈를 정리한다.

작업지시자가 검증부터 공개 배포 및 후속 처리까지 진행을 승인했다. GitHub 보호 규칙과 [공개 릴리즈 절차](../manual/public_release_runbook.md)의 검증 조건을 적용한다.
