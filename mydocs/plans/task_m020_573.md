## 목적과 범위

README 상단에서 실제 포함된 rhwp 버전을 표시하고 macOS 홈페이지에 Windows / Linux 제품 안내 링크를 추가한다. 데스크톱은 공통 헤더, 모바일은 홈페이지 다운로드 영역 아래와 하위 페이지 하단을 사용한다. 기존 문서·배지 스타일과 다른 작업자의 변경을 보존한다. upstream full sync에서 새 pin에 맞춰 배지 표시·릴리스 링크를 유지하는 최소 보완을 포함한다.

## 확인한 기준

`rhwp-core.lock`, `RustBridge/Cargo.toml`·`Cargo.lock`, Studio `manifest.json`과 운영 문서를 대조한다. 최신 devel의 core와 Studio는 모두 `v0.8.6`, resolved commit `f1f9c6ae58344ee9368996d3543f76b9345cf227`이다. 배지는 upstream 최신 릴리스 조회값이 아닌 checkout에 포함된 provenance를 사용한다. 이후 core/Studio가 다른 경우 표시와 링크를 분리한다.

## 제외

rhwp pin 자체, native·Studio 제품 기능, 설치본, 릴리스·서명·공증·공개 배포, PR merge, 원래 `local/task567`의 변경.

## 단계와 검증

1. 배지 및 다음 full sync 유지관리: 현재·다음 버전·core/Studio 차이·commit pin과 stale 표시를 fixture로 검증하고 현재 pin 정합성을 확인한다.
2. 홈페이지와 공통 헤더 하위 페이지 링크: 정적 HTML 구조를 유지하고 작은 화면에서도 링크가 보이도록 공통 CSS를 보완한다. 모든 페이지의 표시·URL과 대표 화면의 잘림·겹침을 확인한다.
3. 종합 검증과 보고: 기존 관련 검증, workflow 문법과 실행 경로, 변경 범위·pin 무변경을 확인하고 보고·커밋·게시한다. Actions는 완료 대기 없이 run 링크를 전달한다.
