# Task M900 #474 수행계획서

## 목적과 범위

main 전용 release transport 이력과 미반영 콘텐츠를 구분한다. helper는 main/source ref를 commit으로 고정하고 complete history를 확인한 뒤 merge-tree로 main을 source에 병합할 결과를 계산한다. ref·index·working tree를 변경하지 않으며 필요한 tree object만 Git object DB에 생성한다.

통과 기준은 충돌 없는 예상 merge tree가 source tree와 같은 경우다. main-only commit 중 두 번째 parent와 tree가 같은 merge는 transport-only로 분류한다. non-merge·source parent와 tree가 다른 merge는 content 후보로 보고하되 실제 merge 결과로 이미 반영된 net content도 허용한다. 단순 전체 main/source tree 동일성이나 patch-id만으로 승인하지 않는다.

shallow/missing ref/unrelated history/지원하지 않는 Git은 명시 실패한다. custom merge driver가 누락 콘텐츠를 숨기지 못하도록 external driver를 사용하지 않는다. equivalent patch가 적용된 경우 실제 tree 결과로 통과를 확인하며 충돌이 남으면 과거 patch 유사성만으로 통과시키지 않는다.
