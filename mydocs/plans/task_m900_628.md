# Task #628 — Threads 장기 토큰 자동 갱신 수행계획서

## 목표

Threads News Sync에 대한 재인증 공백을 줄이도록 만료 14일 전부터 매일 확인하고, 새 토큰과 응답에서 얻은 UTC 만료일을 GitHub Actions에 저장한다. 토큰은 사용자나 CI 로그에 표시하지 않는다.

## 범위

GitHub App 설치는 alhangeul-macos 한 저장소, 쓰기 권한은 Secrets와 Variables로 제한한다. 키는 main 전용 환경에 보관한다. 별도 갱신 워크플로와 요청·저장 검증을 구현한다. 현재 사용자와 뉴스 게시 정책을 유지한다.

## 검증

합성 API와 GitHub 응답으로 유효기간, 계정 확인, 오류 응답, 저장 순서, 재시도·부분 실패, 비노출을 확인한다. main의 수동 검사는 권한 및 계정 접근을 확인하며 만료일과 Secret을 쓰지 않는다. 정기 실행이 갱신 시점에 도달했을 때 실제 두 값과 다음 수집 실행을 확인한다.
