# Task #612 — Quick Look RawSvg 차트 개선 수행계획서

## 목적
Finder Quick Look의 OLE 차트 자리표시자를 개선하고 HWP/PDF 회귀 기준을 고정한다.

## 배경
배포 0.2.4에서 7406_OLE__CHART.hwp의 차트가 SVG 자리표시자로 보인다. 본앱은 사용자 확인상 정상 표시된다. #121의 후속이며 #410의 external image 진단과 구분한다.

## 범위
포함: Quick Look의 RawSvg 렌더 경로 선정·연결, 실패 fallback, 원본 HWP/PDF 회귀 자산, 영역별 시각 비교.
제외: 본앱 변경, OLE 실행/편집, Jangster 제보 동일성 판단, 배포·설치본 교체, 전역 Skia 전환.

## 설계 방향
기존 core 래스터화 기능 재사용을 우선한다. 개체 단위 함수는 비공개이므로 공개 API로 연결 가능한지와 페이지 단위 Skia 대안을 비교한다. 페이지 전환을 택하면 RawSvg가 필요한 페이지만 적용하고 일반 페이지와 폰트 공급 실패의 기존 fallback을 유지한다. 원본·core pin은 변경하지 않는다.

## 예상 변경 파일
Sources/Shared의 Preview renderer, QLExtension 정책, scripts의 회귀 runner, samples/issue7406, 계획·보고 문서.

## 잠정 단계
1. 재현 자산 고정, 공개 API와 baseline 비교.
2. 선정 경로 구현과 정책·fallback 회귀.
3. 빌드·시각 검증, 최종 보고서 및 devel 대상 PR.

## 검증 계획
HWP/PDF 해시 확인, 차트·축·범례·캡션 비교, 손상/과대/외부 참조 RawSvg 제한 확인, 일반 문서 회귀, check-no-appkit, validate-stage3-render, render-debug-compare, HostApp/Preview 빌드. 실제 설치 후보 Finder smoke를 수행하지 못하면 미실행을 명시한다.

## 리스크
Skia 페이지 선택은 주변 글꼴/배치에 영향을 줄 수 있다. core의 RawSvg 폰트 경로와 관리 글꼴 계약은 다르므로 범위를 분리한다. 현재 설치본 교체 없이 직접 렌더 검증과 Finder 설치 smoke를 구분한다.
