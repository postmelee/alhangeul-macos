## 목적과 범위

갱신한 이슈의 범위와 완료 기준을 입력으로 Spotlight importer 앱·빌드·배포 통합 작업을 수행한다. 변경·검증을 단계별로 묶고 .github/pull_request_template.md에 맞춘 PR을 제출한다.

## 단계

1. CFPlugIn importer와 app bundle 통합
2. 서명·universal·CI/package 검증 경로 통합
3. 실제 importer 호출·앱 빌드 검증 및 보고

## 검증 및 제외

단계마다 실제 실행 명령과 근거를 보고한다. 실행할 수 없는 macOS 12 검증은 별도 미실행 상태로 남긴다. core pin/Skia 기본 정책, 공개 서명·공증·배포, PR merge는 포함하지 않는다. 실제 화면 증거가 가능한 단계에서는 합성 화면 대신 실제 스크린샷을 사용한다.
