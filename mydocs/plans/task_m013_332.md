# Task #332 수행계획서 - 외부 PR 리뷰와 완료 처리 Skill 보강

## 목적

외부 기여자 PR 처리 Skill을 PR #331 이후 기준에 맞춰 정리한다. `external-pr-review`는 review 시작 triage, 기여자 피드백 판단, 내부 후속 분리, 응답 전용 코멘트 초안 원칙을 명확히 하고, `external-pr-complete`는 merge 후 PR/Issue 완료 안내와 issue close handoff를 담당하도록 분리한다.

## 배경

PR #331에는 `external-pr-review`의 일부 보강만 포함되었다. 이후 논의에서 첫 기여자 환영, 구체적 칭찬, 실행 가능한 개선 안내, 내부 후속 작업 분리, post-merge 완료 안내가 추가로 필요해졌다.

현재 로컬에는 이 보강 초안이 있으나 `origin/devel` 기준 새 PR에 정리되어 있지 않다. 따라서 Issue #332로 별도 작업 브랜치를 만들고, PR #331 이후의 최신 `devel`과 충돌 없이 필요한 Skill 변경만 반영한다.

## 범위

### 포함

- `mydocs/skills/external-pr-review/SKILL.md` 보강
- `mydocs/skills/external-pr-complete/SKILL.md` 신규 추가
- 수행계획서, 구현계획서, 단계 보고서, 최종 보고서 작성
- 오늘할일 상태 갱신

### 제외

- 실제 외부 PR review/comment 등록
- 실제 GitHub Issue close
- PR #328 검토/완료 문서 변경
- GitHub reviewer/assignee/label/milestone 값을 자동으로 수정하는 실행 스크립트 추가

## 설계 방향

- `external-pr-review`는 merge 전 검토와 작업지시자 판단 지원에 집중한다.
- `external-pr-complete`는 merge/cherry-pick/수동 반영 이후 완료 메시지, issue comment/close, archive handoff를 담당한다.
- 공개 코멘트 초안 전문은 review/report 문서에 저장하지 않고 사용자 응답으로만 제공한다.
- 내부 후속 수정은 외부 PR 안에서 몰래 처리하지 않고 별도 Issue/내부 타스크 후보로 분리한다.
- PR #331에서 도입된 GitHub body-file 검증과 참조 표기 규칙을 보존한다.
