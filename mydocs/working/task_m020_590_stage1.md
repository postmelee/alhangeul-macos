# Task M020 #590 Stage 1 — 글꼴 안내 진입점과 모바일 헤더

## 1. 결론과 승인

**최신 상태: 아래 §6의 Stage 1.1 보정까지 완료했다.** §2~4와 최초 화면/검증은 커밋 `12fcbf69` 당시 기록으로 보존한다. 최신 글꼴 페이지 화면은 §6에 있다.

공통 헤더의 **글꼴 안내**와 홈 v0.2.3 배너의 **Mac 글꼴 설정 방법 →**을 구현했다. 모바일에는 로고/다운로드와 주요 메뉴를 두 줄로 표시하고, 기존 보조 링크는 푸터에서도 접근하게 했다. 기본 데스크톱 1440×1000과 모바일 390×844의 실제 브라우저 화면에서 가로 넘침·헤더 겹침이 없음을 확인했고, 헤더와 배너를 실제 클릭해 글꼴 안내 도착을 확인했다.

2026-10-15 작업지시자의 **“#590 구현계획과 Stage 1 실행을 승인할게. 진행하고 데스크톱·모바일 화면을 보여줘.”**에 따른 실행이다. [구현계획](../plans/task_m020_590_impl.md)의 Stage 1 범위만 완료했다. 전체 화면 폭·경계 폭·하위 페이지·키보드 검증은 Stage 2 승인 후 진행한다. 공개 push/PR·병합·Pages 배포는 실행하지 않았다.

## 2. 변경 결과

- HTML 21개에 상대 경로가 맞는 글꼴 안내 링크와 CSS 참조 버전을 반영했다. 글꼴 페이지는 `aria-current="page"`와 색상/굵기로 현재 위치를 표시한다.
- 홈 배너에 설정 방법 링크를 추가했다. 데스크톱의 배너 링크는 같은 줄로 표시하고, 모바일은 설정 방법을 넓게 누를 수 있는 독립 행으로 둔다.
- 700px 이하에서 높이 100px의 두 줄 sticky 헤더를 사용한다. 주요 메뉴·기존 다운로드는 44px 높이이며 글꼴 안내를 숨기지 않는다. 기존의 아주 좁은 화면 로고 문자 숨김과 페이지별 간격 충돌을 제거했다.
- 820px 이하의 Windows/Linux·GitHub 보조 링크 숨김을 공통으로 정리하고 푸터 목적지를 유지/추가했다. 최신 소식에는 같은 목적의 작은 푸터를 추가했으며 feed 본문은 유지했다.
- 최신 소식·문의의 현재 다운로드 URL과 접근성 이름을 v0.2.3으로 맞췄다. 과거 릴리즈별 다운로드는 그대로다.
- 글꼴 목차의 스크롤 여백이 실제 헤더 높이를 참조하게 하고, 관련 초점·현재 위치 규칙을 공통 위치에 정리했다.

## 6. Stage 1.1 — 글꼴 안내 페이지의 헤더 통일·파란 문구 제거

### 승인과 변경

2026-10-15 작업지시자가 **“동의해. #590 계획에 보정 범위를 반영하고, 글꼴 안내 페이지의 헤더를 다른 페이지와 통일하고 파란 안내 문구는 제거해줘. 수정한 데스크톱·모바일 화면도 보여줘.”**라고 지시했다. 소스 수정 전에 수행/구현계획의 간결한 헤더 예외와 본문 보존 계약을 보정했다. 전체 Stage 2를 시작한 것은 아니다.

글꼴 안내 헤더를 홈과 같은 메뉴 순서·클래스·현재 공개 다운로드 버튼으로 통일했다. 상대 경로와 글꼴 안내의 현재 위치 표시만 해당 페이지에 맞춘다. 별도 홈 메뉴는 제거했으며 로고가 홈으로 연결된다. 본문 상단의 파란 ‘Mac 글꼴 사용 안내’ 한 줄과 쓰이지 않게 된 CSS만 제거했다. 큰 제목·설명·기능 안내·목차·나머지 본문은 유지한다.

### 검증과 화면

- [보정 구조 검사](../report/assets/task_m020_590/stage1-1/structural-check.json): 기존 `be8f4663` manifest를 유지하고 원문에서 승인한 p 한 줄만 뺀 결과와 대조 PASS. 홈/글꼴 헤더 링크 속성은 상대 경로 해석·현재 위치를 제외하고 일치한다. 글꼴 헤더에 추가한 현재 다운로드 한 개 외 기존 다운로드와 이전 릴리즈 본문·배너, 저장소 appcast는 유지했다.
- [브라우저 기록](../report/assets/task_m020_590/stage1-1/browser-checks.json): 데스크톱 1440×1000과 모바일 390×844에서 가로 넘침 없음, 현재 메뉴 ‘글꼴 안내’ 한 개, 파란 안내 문구 제거 확인. 모바일 주요 링크·다운로드 높이 44px. 화면에서 헤더와 본문 겹침 없음.
- 모바일에서 로고 클릭 → `/`, 헤더의 글꼴 안내 클릭 → `/fonts/` 도착을 확인했다. 다운로드는 클릭하지 않았다.
- `git diff --check`·문서 링크·JPEG 형식·[checksum](../report/assets/task_m020_590/stage1-1/SHA256SUMS) 검사 PASS. 첫 Stage 1의 원본 manifest·기존 화면·증거는 덮어쓰지 않았다.
- [글꼴 안내 미리보기](http://127.0.0.1:61371/fonts/)를 해당 탭에 열어 두고 임시 viewport는 기본 크기로 복원했다. 기존 전용 서버를 그대로 사용하고 앱/미디어 복사본을 만들지 않았다.
