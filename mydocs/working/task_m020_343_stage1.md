## 정합성 점검

README의 공개 버전은 v0.1.11 (17), core는 v0.8.6 pin이다. #337의 목표 v0.2.0은 아직 릴리스 태그/빌드 번호를 결정하지 않았다. 이번 단계에서 공개 표시나 binary 값을 수정하지 않았다.

| 주장 | 실제 근거 | 문서에 사용할 표현 |
|---|---|---|
| HWP3/HWP5/HWPX 추출 | Rust 계약 및 세 형식 실제 mdimport PASS | 평문 지원 대상, 추출 확인 |
| 표/글상자/각주 등 본문 | 모델 순회 구현·합성 회귀 | 저장 모델 기준, 시각 읽기 순서 보장 없음 |
| 암호/DRM/배포용 제외 | ABI 및 실제 importer metadata 전환 PASS | 본문 미제공, 기존 색인의 즉시 제거 보장 없음 |
| 파일/출력 한도 | 32 MiB / 1 MiB / 200,000 / 64 | 한도 뒤 내용은 누락될 수 있고 parser 전체 자원 제한 아님 |
| 실제 Spotlight 검색 | txt 대조부터 환경 실패 | 검색 성공·삭제 전파 미검증 |
| 설치/교체 | 개발 등록 후 추출, 로컬 교체 후 재발견 PASS | 일반 신규 사용자 설치·공개 Sparkle 성공과 구분 |
| 정리 | 원래 앱/provider 보존·시험 제거·목록 제거 PASS | 시험만 정리, 기존 두 앱/과거 레코드 보존 |
| OS/architecture | 최신 OS arm64 실행, universal min12 build | macOS 12 및 Intel runtime 미실행 |

## 문서 배치와 계획

사용자 지원 안내와 운영 smoke는 manual로, 이번 v0.2.0의 한시적인 검증 상태는 release 초안으로 분리한다. README의 공개 기능 목록에 Spotlight 완료 체크를 넣지 않는다. 기존 설계 문서의 후속 예정 표현은 실제 계약 문서 링크로 최신화한다.
