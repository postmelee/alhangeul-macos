# #615 3단계 — 최초 열기와 문서 교체 회귀 검사

실제 HostApp의 Store, SwiftUI 화면, WKWebView와 공개 정렬 샘플을 사용했다. 문서별 첫 캔버스를 192×256으로 축소하고 어두운 픽셀 수와 그 x좌표 합을 대조했다. 상태 표시줄 파일명, 쪽 캔버스 수, 빈 자리표시자 제거, 로드 횟수도 검사했다.

| 문서 열기 | 첫 페이지 픽셀 수 / x좌표 합 | 결과 |
|---|---|---|
| A 정상 | 294 / 26534 | 1쪽 |
| B 정상 | 314 / 32791 | 1쪽 |
| A 글꼴 완료 1회 | 294 / 26534 | A와 일치 |
| A 글꼴 완료 8회 | 294 / 26534 | A와 일치 |
| A 준비 대기 중 B로 전환 | 314 / 32791 | 지연 시간 경과 후 B와 일치 |
| A 명시적 재열기 | 294 / 26534 | A와 일치 |

경합 검사는 글꼴 리스너의 FontFaceSet에 이벤트를 전달하고 페이지 목록이 비어 있는 동안 렌더 세대가 증가했는지 확인한다. 테스트 전용 지연·계측은 진단 앱 사본에만 주입한다. 픽셀 절대값은 이 Mac의 관측값이며 CI는 같은 실행의 대조 문서와 비교한다.
