# #615 1단계 — 수정 전 HostApp 대조군

공개 정렬 합성 문서를 실제 ContentView와 DocumentViewerStore로 한 번 열었다. 정상 실행은 쪽 캔버스 1개, 자리표시자 없음이었다. 초기 metrics 호출 중 loadingdone 1회를 주입한 실행에서 렌더 세대 1 → 2, WASM 1쪽, 캔버스 0개, 자리표시자 유지와 파일명·1페이지 완료 표시를 함께 관측했다. 주입 후 정상 표시된 실행도 있었다. 강제 경합의 결과이며 자연 재현 빈도는 측정하지 않았다. 로그와 창 스냅샷은 외장 검증 디렉터리에 보관했다.
