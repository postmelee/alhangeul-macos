# #615 2단계 — 최초 렌더 완료 조건

최초 로드는 문서 세대와 로드 번호를 기록하고 같은 문서에서 이미 시작된 최신 렌더 준비를 기다린다. 글꼴 통지가 선택을 교체해도 문서를 다시 열거나 새 선택을 요청하지 않는다. 문서 교체·dispose 시 이전 호출은 완료 이벤트를 발행하지 않는다. initializeDocument는 현재 문서의 페이지 구성에 성공해야 최종 메시지를 게시한다.

고정된 v0.9.0 소스와 기존 WASM으로 Studio를 빌드했다. 변환 위치의 유일성, TypeScript 검사, Vite 빌드, upstream Cargo.lock 및 번들 증명, 자산 해시, 기존 글꼴 계약 8건과 Cargo.lock 검증 fixture가 통과했다.
