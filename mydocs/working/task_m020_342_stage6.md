# Task M020 #342 Stage 6 — 리뷰 진단 보완과 최초 설치 검증 이관

## 변경

run()이 로그 인자 없는 실패에 see None만 남기던 문제를 보완했다. 명령 이름·종료 코드와 마지막 8줄/최대 2,000자의 캡처 출력을 오류에 포함한다. 로그 경로가 있으면 전체 출력을 보존한다. timeout도 bytes/str 부분 출력을 정상화해 제한 요약과 로그로 남긴다. verify()의 미사용 지역 변수를 제거했다.

현재 환경에서 pluginkit 매치 없음은 exit 0이었다. 따라서 모든 non-zero를 빈 provider로 바꾸는 check=False 제안은 적용하지 않았다. 정상 빈 집합과 실제 서비스 오류를 각각 회귀로 고정했다. 명령 timeout 한도와 명시 cleanup 단계는 유지하며 timeout을 무제한 대기로 바꾸지 않는다.

최종 보고서에 2026-09-09 최신 결과 표와 증거 링크를 올리고, 과거 FAIL/MISS 표는 실행일과 현재 판정에 쓰지 않는다는 설명을 붙였다. 최초 설치 원인 분리·해결은 #513 후속 이슈가 담당하고 이 단계는 완료된 검증 도구의 리뷰 보완만 수행한다.
