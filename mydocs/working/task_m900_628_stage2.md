# Task #628 Stage 2 — 갱신 및 회귀 검증

기존 Meta 토큰 응답 검증을 공유한다. 정기 작업은 갱신 대상만 처리하고 수동 작업에서는 조회만 수행한다. 토큰은 메모리와 자식 프로세스의 표준 입력으로 전달한다. 두 가지 쓰기 작업을 각각 재시도하고 사후 메타데이터를 조회한다.

합성 갱신 8개, 기존 Threads 43개, Pages 14개가 통과했다. 운영 GitHub App 설치 권한과 실제 갱신은 별도로 확인한다.

[운영 실행](https://github.com/postmelee/alhangeul-macos/actions/runs/45027788510)은 공식 App 토큰 액션에 없는 Variables 개별 권한 입력에서 실패했다. 전용 앱 설치의 쓰기 권한을 그대로 요청하도록 보완했다. 승인된 대상 저장소 하나와 main 환경에서만 사용한다.
