# Task M020 #513 Stage 12 — 재설치 증거 없는 공개 승격 차단

검증 결과 schema를 2로 올리고 최초 설치·종료 후·재설치·재설치 종료 후·cleanup snapshot을 하나의 후보/소유 식별과 누적 결과 이력으로 연결했다. 설치 객체 변화, 기존 요청 기록 유지와 새 식별자, 같은 경로/빌드/mtime, 원본 corpus 보존과 단일 재설치 실행을 확인한다. 재설치 종료 후에는 재설치 검색 snapshot 이후에 기록된 종료와 후속 검색이 있어야 하므로 최초 종료 기록을 재사용할 수 없다.

공개 승격 artifact에서 `reinstall-search.json`, `reinstall-stopped-search.json`을 필수로 읽고 동일 판정 함수를 적용한다. schema 1이나 재설치 파일이 없는 과거 성공 증거로 새 관문을 통과하지 못한다. 과거 공개 릴리스/태그/검증 기록은 변경하지 않는다.

- 설치 회귀 18개 PASS: 최초 설치만 있는 증거, 보조 등록, 재실행 추가, 설정 초기화, 같은 요청 식별자, 빌드/mtime 변경, 교체 객체/원본 corpus 불일치, 사전 미검색 누락, 재설치 종료 생략 거부.
- 승격 회귀 15개 PASS: 구형 schema·재설치 snapshot 누락을 API 판정 및 실제 ZIP에서 거부. 기존 출처/최신 회차/자산 동일성/모의 API CLI 회귀 유지.
- 실제 서명 후보 VM 검증은 후속 릴리즈에서 수행한다. 회귀의 모의 publish 출력은 네트워크 배포가 아니다.
