# 다음 릴리즈: 실제 Mac Spotlight 검색의 사용자·도구·계정 환경 원인 분리

## 목적

v0.2.3 수용에서 남은 실제 Mac Spotlight 본문 검색을 재검증한다. 제품 회귀·OS 색인 오류·도구 접근 제한을 아직 확정하지 않았으며, 원인 분리 후 필요한 제품 또는 검증 도구 수정만 수행한다. #584 배포와 분리해 다음 릴리즈 전 확인한다. 마일스톤 제안은 Release Operations / M900이다.

## 근거와 현재 한계

- v0.2.3/21 동일 DMG SHA256 d0050cb7de5d3fea17708aef1bebb7da54d326c7a540afbaf28276c3e50b1e63. 양 ARM/Intel VM 최초 설치·재설치/종료 후 검색 PASS와 실제 Mac importer 본문 추출 PASS를 작업지시자가 대체 근거로 수용했다.
- 현재 실제 Mac에서 TXT도 검색되지 않았으며, 도구 sandbox 안/밖 조회 차이와 설치 전 한 차례 양성 후 재실패를 관측했다. 실제 Finder 자동 조작도 0개였으나 사용자 직접 검색과 완전히 같은 검증이라고 단정하지 않는다.
- 재부팅과 고유 폴더만 검색 제외에 추가/제거한 시험 후에도 한도 안에서 TXT 양성 전제를 충족하지 못했다. 사용자는 인덱싱 중이라고 설명했고 직접 TXT 검색을 시험 중이다.
- 최신 공개본이었던 v0.2.2는 배포 당시 실제 Mac/VM 검색을 통과했다. 현재 환경에서 v0.2.2/v0.2.3 A/B를 새로 수행한 것은 아니다. 기존 #513 이슈는 이미 v0.2.2 근거로 종료됐으며 같은 결함으로 재분류하지 않는다.

## 순서와 완료 기준

- [ ] 현재 계정에서 사용자가 직접 일반 TXT 본문을 Spotlight/Finder·일반 Terminal에서 검색하고 도구의 동일 조건 조회와 비교한다. 검색 범위·내용/이름 조건·대기 시간·동일 파일을 기록한다.
- [ ] 필요하면 별도 표준 사용자 계정의 홈 폴더에 새 TXT를 만들어 비교한다. 계정 생성/로그인은 구체 승인·사용자 동작으로 진행하며 같은 OS/디스크의 공유 한계를 기록한다.
- [ ] TXT 전제가 정상인 환경에서 공식 v0.2.2와 v0.2.3의 HWP/HWPX 최초 발견·본문·종료 후 검색과 결과 열기를 비교한다. 원본·기본 앱·문서·설정을 보존한다.
- [ ] 도구 조회만 실패하면 검증 도구·접근 방식을 수정하고, 제품 회귀이면 별도 승인한 최소 제품 수정을 검증한다. OS 환경 문제이면 재현 조건·해결 절차와 정상 대조를 기록한다. 원인 미확정 상태를 단일 제품 결함으로 닫지 않는다.
- [ ] 실제 사용자 동선의 정상 검색 또는 남은 검증 한계·지원 절차를 다음 릴리즈 완료 기준에 연결한다.

전역 색인·캐시 초기화, 권한 확대, 계정 생성, 실제 앱 교체/배포는 이 이슈 등록만으로 실행하지 않는다. 별도 수행/구현계획과 구체 실행 범위를 따른다.
