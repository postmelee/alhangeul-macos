# Task M900 #535 Stage 2 완료보고서

재설치 복사 전과 실행 전 영문 3개·한글 2개·TXT 대조를 함께 조회한다. 4초 이상 안정적인 전체 미검색 또는 전체 검색만 기록하며, 부분 검색·TXT 부재·명령 오류는 PASS로 사용하지 않는다. 첫 설치 사전 미검색과 제거된 문서의 삭제 전파 검증은 유지한다.

실행 전 이미 검색되면 `maintained`, 미검색이었다가 두 번째 실행 후 검색되면 `recovered`로 분류한다. 이미 검색된 경우를 재색인 복구 증거로 표현하지 않는다. 양 경우 모두 같은 bytes/경로/mtime, 기존 요청 기록 보존, 새 설치 객체와 새 요청, 두 번째 실행과 종료 후 검색, lifecycle·정리가 필요하다. schema 3의 관찰 내용·시간·순서·분류 및 snapshot 연결을 승격 시에도 검사한다. schema 2 증거를 재해석하지 않는다.

운영 smoke 40개·설치 23개·승격 15개 회귀 PASS. 전체/미검색 수용, 부분·TXT 부재·조회 오류 거절, 유지 결과를 복구로 바꾼 증거 거절, 관찰 변조·누락·이전 schema 차단을 포함한다. 실제 VM 실행은 아직 수행하지 않았으며 양 아키텍처 결과는 도구 검토·main 반영 후 별도로 남긴다.
