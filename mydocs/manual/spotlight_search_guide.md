# Spotlight 문서 본문 검색 안내

## 기능과 제공 상태

알한글의 Spotlight importer는 파일명에 없는 본문 단어로 HWP/HWPX 문서를 찾을 수 있도록 macOS 검색 색인에 텍스트를 제공합니다. Finder 검색과 Spotlight가 이 색인을 사용하며, 알한글 앱 안의 찾기와는 별도 기능입니다. 앱이 종료된 상태에서도 시스템이 importer를 호출할 수 있습니다.

**현재 개발 중인 기능입니다.** 배포 여부와 검증 상태는 [README의 현재 작업 축](../../README.md#현재-작업-축) 및 [릴리스 기록](../release/index.md)에서 확인하세요. 아래 범위는 구현 정책이며, 모든 문서의 검색 성공을 보증하지 않습니다.

## 어떤 내용을 검색하나요?

| 항목 | 범위 |
|---|---|
| 파일 형식 | 평문 HWP3, HWP5, HWPX |
| 본문·표 | 저장된 문단, 표/중첩 표의 셀, 캡션 |
| 글상자·도형 | 저장된 글상자 문단, 그룹 안 글상자, 캡션 |
| 머리말·꼬리말·각주·미주 | 저장된 문단; 페이지마다 반복하지 않음 |
| 수식·양식 | 저장된 수식 script, 양식 text/caption; 화면 모양과 다를 수 있음 |
| 링크·필드 | 문단에 저장된 표시 문자열; URL·명령·메모 payload를 추가하지 않음 |
| 그림 | 캡션만; 이미지 속 글자나 스캔 문서 OCR 제외 |

문서 모델의 문단과 컨트롤 순서로 추출하므로 화면의 읽기 순서나 모든 자동 번호·페이지·날짜를 재현하지 않습니다. 메모·숨은 설명 전용 데이터와 바탕쪽, 그림·차트·OLE의 내부 데이터는 추출 대상에서 제외합니다. **흰색 글자나 스타일로 가린 일반 본문은 검색에 포함될 수 있습니다.** 화면에서 보이지 않게 만드는 것은 색인 제외 방법이 아닙니다.

## 제외되는 파일과 한도

- 암호·DRM·배포용 문서는 본문을 제공하지 않습니다. 암호 입력 창을 열거나 앱에 저장한 비밀번호를 사용하지 않습니다. 앱 뷰어에서 열 수 있는 문서라도 검색 대상에서는 제외될 수 있습니다.
- 손상·미지원·읽기 실패·빈 문서는 검색 가능한 본문이 없을 수 있습니다. 이 경우 파일명 기반 제목·종류만 제공할 수 있습니다.
- 원본 파일이 **32 MiB**를 초과하면 본문을 읽지 않습니다. 출력은 최대 **1 MiB UTF-8**, 순회는 **200,000개 방문 단위 / 깊이 64**로 제한하며 뒤쪽 내용이 검색에서 빠질 수 있습니다. Finder 미리보기의 크기 제한과는 다른 기준입니다.
- 출력/순회 한도는 파싱 후 적용되므로 압축 해제나 parser 전체의 시간·메모리 상한을 보장하지 않습니다.

## 설치·업데이트와 검색 지연

importer는 앱에 포함됩니다. 앱 설치 후 첫 실행과 시스템 발견·색인이 진행되어야 하며, 문서 수와 Spotlight 상태에 따라 검색까지 시간이 걸릴 수 있습니다. 업데이트에서는 새 importer의 변경 시각이 발견과 재색인에 영향을 줍니다. 앱 복사나 `mdimport -t` 추출 시험만으로 기존 파일의 색인이 완료됐다고 볼 수 없습니다.

검색할 폴더가 Spotlight 검색 제외 위치에 있거나 `.noindex`/임시 디렉터리인 경우 색인되지 않을 수 있습니다. 먼저 해당 폴더에 있는 일반 텍스트 파일을 검색해 환경을 확인하세요. 앱에 검색 기능을 추가하는 것만으로 사용자의 검색 제외 설정이 해제되지는 않습니다.

문서를 수정·보호·삭제한 뒤에도 검색 결과 변경은 비동기입니다. importer는 실패·보호·빈 결과에 이전 본문을 제거하는 metadata를 제출하지만 **기존 검색 단어의 즉시 제거를 보장하지 않습니다.** 앱 제거도 이미 색인된 문서 내용의 즉시 삭제나 비밀 정보 삭제 기능이 아닙니다. 관련 검색 제외·재색인은 [Apple Spotlight 안내](https://support.apple.com/en-gb/102321)를 확인하세요.

## 문서 내용의 처리

importer는 로컬 원본을 읽기 전용으로 열고 추출 본문을 macOS Spotlight 색인에 전달합니다. importer 자체는 문서 본문을 네트워크로 보내거나 별도 앱 검색 데이터베이스·본문 로그를 만들지 않습니다. 외부 이미지/URL/첨부 문서를 열지도 않습니다. macOS가 관리하는 색인에는 추출 내용이 보관되므로, 기밀 문서의 노출 범위를 판단할 때 이 점과 가시성·삭제 지연을 함께 고려하세요.

## 검증과 문제 구분

| 관찰 | 다음 확인 |
|---|---|
| importer가 목록에 없음 | 설치 위치, 앱 첫 실행, bundle timestamp 및 서명 |
| 목록에는 있지만 다른 importer 선택 | 실제 문서 UTI와 `mdimport -t`의 선택 경로 |
| 추출 본문 자체가 비어 있음 | 보호 여부, 지원 형식, 크기·출력 한도와 parser 결과 |
| 본문은 추출되지만 검색 안 됨 | 같은 위치의 일반 txt 대조, 검색 제외 설정, 실제 볼륨 색인 상태 |
| 수정·삭제 후 이전 단어가 남음 | 재색인/삭제 전파 대기와 실제 결과 집합; 즉시 삭제로 간주하지 않음 |

maintainer는 [표준 Spotlight smoke](build_run_guide.md#spotlight-설치색인-smoke)로 실제 importer 선택, metadata, 본문 검색, 전환·교체·정리를 분리해 확인합니다. `mdls` 본문 출력이나 Quick Look/Thumbnail provider 성공을 본문 색인 성공의 근거로 사용하지 않습니다. 일반 색인이 정상인 환경, 최소 지원 OS와 공개 서명·공증 설치본에서도 결과를 기록해야 합니다.

상세 추출 순서와 ABI는 [본문 추출 계약](../tech/spotlight_text_extraction_contract.md), 실제 시험 범위와 화면은 [설치 smoke 보고서](../report/task_m020_342_report.md)를 참조하세요.
