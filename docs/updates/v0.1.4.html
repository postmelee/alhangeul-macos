알한글 v0.1.4

업스트림 rhwp v0.7.13을 반영해 HWPX 렌더링과 HWP 저장 호환성, 시험지와 공공기관 문서 회귀 수정을 포함한 패치 릴리즈입니다.

DMG 다운로드 GitHub Release 업데이트 목록

전체 요약

  • rhwp core와 bundled rhwp-studio를 v0.7.13 기준으로 갱신했습니다.
  • HWPX 렌더링과 HWP 저장 호환성, 표/셀 속성, 메모와 목차 필드, 페이지 번호 처리 관련 upstream 수정이 포함됩니다.
  • 시험지와 공공기관 문서에서 발견된 배경쪽, 머리말/꼬리말, 문단 번호, 문단 테두리, 시험 문항 상자 회귀 수정을 포함합니다.
  • 앱 본체, Quick Look preview, Finder thumbnail extension의 release version을 0.1.4 (10)로 맞췄습니다.
  • 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용하는 signed/notarized universal DMG 기준을 유지합니다.

포함된 rhwp 변화

v0.1.4는 rhwp v0.7.13 기준의 core와 bundled rhwp-studio를 사용합니다. 앱 내부 provenance 기준 commit은 b3e16ef212af81ef37d973ddb86d6816d3804642입니다.

  • HWPX에서 HWP로 저장할 때 표와 셀 속성, gradient border fill, 셀 내부 여백, 셀 배경 이미지, 메모, 목차 필드, 페이지 번호 control 처리를 보강했습니다.
  • 렌더링 경로에는 배경쪽, 머리말/꼬리말, 문단 번호, 텍스트박스 위치와 gradient/rounding, 문단 테두리, 시험 문항 상자 관련 수정이 포함됩니다.
  • 페이지 나눔과 배치에서는 treat-as-char 표 높이, 중첩 표 page split, 이미지 pushdown/vpos, 다단 각주 vpos, 하단 overflow 측정 보정이 포함됩니다.
  • rhwp-studio에는 TAC shape cursor 이동, 연속 공백 이동, Chrome file:// 안내, 중복 다운로드 억제 개선이 포함됩니다.

알한글 앱 변화

  • About 창과 내부 provenance 기준이 rhwp v0.7.13을 표시할 수 있도록 core lock과 bundled manifest 기준을 유지합니다.
  • release rehearsal/publish workflow의 기본 입력을 v0.1.4, 직전 공개 릴리즈 v0.1.3, expected rhwp v0.7.13 기준으로 정리했습니다.
  • README, Pages 업데이트 목록, 릴리즈 기록을 0.1.4 (10)과 rhwp v0.7.13 기준으로 맞췄습니다.

알려진 한계

  • Quick Look과 Finder 썸네일은 native 렌더 경로를 사용하고, 앱 화면은 WKWebView 기반 rhwp-studio 경로를 사용합니다.
  • 일부 문서에서는 글꼴, 배치, 페이지 표현이 원본 한글 프로그램과 다르게 보일 수 있습니다.
  • HWPX 문서는 직접 저장이 제한되어 HWP 내보내기 경로를 사용합니다.

설치와 업데이트

DMG 파일을 내려받아 앱을 Applications 폴더로 옮긴 뒤, 앱을 한 번 실행합니다. v0.1.4 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew Cask를 사용하는 경우 아래 명령으로 같은 signed/notarized universal DMG를 설치할 수 있습니다.

brew install --cask postmelee/tap/alhangeul

설치한 앱에서는 메뉴 막대의 알한글 > 업데이트 확인...을 선택해 새 버전을 확인할 수 있습니다.
