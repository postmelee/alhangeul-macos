알한글 v0.1.4

Quick Look과 Finder 썸네일에서 일부 HWP 문서의 특수 기호 깨짐과 텍스트 배경 표시를 보정하고, rhwp v0.7.13의 문서 호환성 개선을 함께 반영한 패치 릴리즈입니다.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • 일부 HWP 양식 문서에서 특수 기호나 서명 표식이 깨진 네모처럼 보이던 문제를 Quick Look과 Finder 썸네일에서 보정했습니다.
  • 일부 문서에서 글자 뒤에 의도하지 않은 배경색이나 음영 박스가 보이던 문제를 줄였습니다.
  • HWPX 렌더링과 HWP 저장 호환성, 표/셀 속성, 메모, 목차 필드, 페이지 번호 처리 관련 rhwp v0.7.13 개선을 포함했습니다.
  • 머리말/꼬리말, 문단 번호, 문단 테두리, 시험 문항 상자처럼 양식 문서에서 자주 눈에 띄는 배치 요소의 회귀 수정을 포함했습니다.
  • 앱 본체, Quick Look 미리보기, Finder 썸네일 extension을 0.1.4 (10) 기준 signed/notarized universal DMG로 배포합니다.

포함된 rhwp 변화

v0.1.4는 rhwp v0.7.13 기준의 core와 bundled rhwp-studio를 사용합니다. 앱 내부 provenance 기준 commit은 b3e16ef212af81ef37d973ddb86d6816d3804642입니다.

  • HWPX 문서를 HWP로 내보낼 때 표와 셀 속성, 셀 배경, 메모, 목차 필드, 페이지 번호 같은 문서 구조가 더 안정적으로 보존됩니다.
  • 배경쪽, 머리말/꼬리말, 문단 번호, 텍스트박스 위치, 문단 테두리, 시험 문항 상자처럼 인쇄 양식에서 눈에 띄는 배치 요소의 렌더링 수정이 포함됩니다.
  • 페이지 나눔과 이미지/표 배치가 어긋나거나 하단 내용이 넘쳐 보이는 일부 상황을 줄이는 보정이 포함됩니다.
  • 앱 내부 viewer asset에는 도형 커서 이동, 연속 공백 이동, 브라우저 파일 열기 안내, 중복 다운로드 억제 개선이 포함됩니다.

알한글 앱 변화

  • Quick Look 미리보기와 Finder 썸네일에서 일부 HWP 문서의 특수 문자, 기호, 서명 표식이 깨진 네모로 보이지 않도록 표시를 보정했습니다.
  • 기본 미리보기 렌더러가 텍스트 배경/음영 값을 더 정확히 해석해, 글자 뒤에 불필요한 배경 박스가 생기는 문제를 줄였습니다.
  • 앱 본체와 Quick Look/Thumbnail extension을 0.1.4 (10)으로 맞추고, GitHub Release, Sparkle 업데이트, Homebrew Cask가 같은 signed/notarized universal DMG를 가리키도록 정렬했습니다.
  • About 창과 내부 provenance 정보는 bundled rhwp v0.7.13 기준을 표시합니다.

알려진 한계

  • Quick Look과 Finder 썸네일은 native 렌더 경로를 사용하고, 앱 화면은 WKWebView 기반 rhwp-studio 경로를 사용합니다.
  • 일부 문서에서는 글꼴, 배치, 페이지 표현이 원본 한글 프로그램과 다르게 보일 수 있습니다.
  • HWPX 문서는 직접 저장이 제한되어 HWP 내보내기 경로를 사용합니다.

설치와 업데이트

DMG 파일을 내려받아 앱을 Applications 폴더로 옮긴 뒤, 앱을 한 번 실행합니다. v0.1.4 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew Cask를 사용하는 경우 아래 명령으로 같은 signed/notarized universal DMG를 설치할 수 있습니다.

brew install --cask postmelee/tap/alhangeul

설치한 앱에서는 메뉴 막대의 알한글 > 업데이트 확인...을 선택해 새 버전을 확인할 수 있습니다.

알한글

Mac을 위한 HWP/HWPX 문서 미리보기 및 편집 앱입니다. 한글 파일이 더 이상 낯선 파일로 남지 않도록 만듭니다.
