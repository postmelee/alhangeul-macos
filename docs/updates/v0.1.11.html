알한글 v0.1.11

암호 문서·HWP3 원본 저장 보호, PDF 한글 텍스트와 열기·색상 선택기 개선, rhwp v0.8.6을 포함하는 패치 릴리즈입니다.

2026년 9월 7일 공개. 아래에서 공식 DMG를 내려받거나 앱의 업데이트 확인 메뉴를 이용하세요.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • 암호 문서와 HWP3 저장 시 원본을 보존하고, 변환·보호 해제를 안내한 뒤 새 복사본으로 저장합니다.
  • PDF의 한글 선택·검색·복사와 PDF·인쇄의 반복 실행을 보강했습니다.
  • 지원하지 않는 파일을 열어도 기존 문서를 유지하며 다시 시도할 수 있습니다.
  • 글자색 선택기의 표시·위치를 보정하고 형광펜의 기본·사용자 지정 색상 선택 흐름을 유지했습니다.

포함된 rhwp 변화

문서 처리 엔진과 편집 화면에 rhwp v0.8.6을 함께 반영했습니다.

  • 표의 페이지 분할, 글상자·개체와 특수 글리프 배치를 보정했습니다.
  • HWPX 개체·본문과 HWP3 본문을 보존하는 열기·저장 경로를 넓혔습니다.
  • 한글 입력, 머리말·꼬리말, 배율·표 크기 조절과 중첩 표의 검색·치환을 개선했습니다.

알한글 앱 변화

  • 보호 문서는 보호 해제를 안내한 뒤 새로운 평문 복사본으로 저장합니다. HWP3는 새 HWP5 또는 HWPX 변환 복사본으로 저장하며 기존 파일을 덮어쓰지 않습니다.
  • PDF에 한글 문자 대응 정보를 포함해 뷰어에서 선택·검색·복사할 수 있는 범위를 보강했습니다.
  • PDF·인쇄 중복 실행과 이전 작업의 늦은 응답을 차단해 취소·오류 뒤 다시 실행하는 경로를 안정화했습니다.
  • 미지원 형식, 빈 파일과 읽기 실패 시 기존 문서·편집 상태를 유지하고 닫기·다시 시도 안내를 표시합니다.
  • macOS에서 글자색 선택기가 나타나지 않거나 버튼과 어긋나는 문제를 수정했습니다.

알려진 한계

  • 암호 보호를 유지하는 저장과 새 암호 설정은 아직 지원하지 않습니다. 보호 문서는 사용자 확인 뒤 새 평문 복사본으로만 저장합니다.
  • HWP3 원형 저장은 지원하지 않습니다. 새 HWP5 또는 HWPX로 변환하며 모든 문서 요소의 완전한 보존을 보장하지 않습니다.
  • PDF의 읽기·선택 순서는 뷰어마다 다를 수 있습니다. 일부 수식·기호·글꼴은 완전한 텍스트 선택을 보장하지 않으며 이미지·스캔 문자의 OCR은 제공하지 않습니다.
  • 색상 선택기의 키보드 활성화 수정은 rhwp v0.8.6 이후 변경으로 이번 번들에 포함되지 않습니다. 혼합 글자색 범위에 형광펜을 적용한 뒤에는 기존 서식을 확인하세요.
  • 문서 파싱 실패 등은 기존 오류 화면을 사용합니다. 열기 실패 안내가 손상 파일을 복구하는 기능은 아닙니다.
  • 앱과 Finder 미리보기는 렌더링 경로가 달라 일부 문서의 글꼴·배치가 다르게 보일 수 있습니다. 큰 문서의 PDF 내보내기는 메모리와 시간이 더 필요하며 문서 전체 진행률·수집 중 취소 UI는 아직 없습니다.

설치와 업데이트

공식 DMG를 내려받아 앱을 Applications 폴더로 옮기고 한 번 실행하세요. macOS 12 이상, Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew에서도 brew install --cask postmelee/tap/alhangeul로 같은 v0.1.11 공식 DMG를 설치할 수 있습니다.

설치한 앱에서는 알한글 > 업데이트 확인... 메뉴로 새 버전을 확인할 수 있습니다.
