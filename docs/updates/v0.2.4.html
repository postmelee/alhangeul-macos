알한글 v0.2.4

편집 중 오류가 발생하면 복구 결과를 확인하고 같은 창에서 작업을 이어갈 수 있습니다. 문서에 지정된 딸기 글꼴과 굵기도 화면과 PDF에 반영합니다.

배포 상태와 공개일은 GitHub Release에서 확인하세요.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

오류 안내에서 편집을 계속할 수 있는지 확인하고, 문제를 제보할 때는 상세 정보를 복사할 수 있습니다.

알한글 앱 변화

  • 문서가 복구되면 실행 취소, 다시 실행, 저장을 이어갈 수 있습니다. 복구를 확인할 수 없으면 편집과 저장을 멈춰 이전 저장본을 보호합니다.
  • 여러 구역을 한꺼번에 삭제하려 하면 내용과 선택 영역을 유지합니다. 삭제할 때는 한 구역씩 선택하세요.
  • 딸기 글꼴 파일을 가져오면 HWPX를 처음 열 때부터 조판에 사용합니다. 확인한 HWP3·HWPX 문서에서는 딸기 Regular만 있어도 굵게 지정한 글자를 PDF에서 원래 굵게 효과로 표시하며 텍스트를 검색하고 복사할 수 있습니다.

글꼴 파일을 추가하는 방법은 Mac 글꼴 사용 안내에서 확인하세요.

포함된 rhwp 변화

문서 엔진과 내장 편집기를 rhwp v0.9.0으로 갱신했습니다. 기본 글꼴 서버가 응답하지 않을 때도 대체 글꼴로 문서를 열 수 있습니다.

알려진 한계

  • 그림이 있는 일부 HWPX 문서에서는 가운데 정렬한 글줄이 한컴 출력보다 약 4pt 오른쪽에 놓일 수 있습니다.
  • Finder와 Spotlight에서 본문을 찾을 수 있는지는 Mac의 색인 상태와 검색 제외 설정의 영향을 받습니다.

설치와 업데이트

DMG에서 앱을 Applications 폴더로 옮기고 한 번 실행하세요. macOS 12 이상, Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

최초 실행 후 검색 준비와 문서 색인에 시간이 걸릴 수 있으므로, 처음에는 앱을 켜 둔 채 잠시 기다려 주세요. 소요 시간은 Mac의 상태와 문서 수에 따라 달라집니다.

메뉴 막대에서 알한글 → 업데이트 확인…을 선택하세요.

Homebrew의 현재 제공 버전과 명령어는 Homebrew 설치·업데이트 안내에서 확인하세요.
