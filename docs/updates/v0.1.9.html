알한글 v0.1.9

rhwp v0.8.2 문서 처리·편집 개선, 반응형 툴바와 Finder 썸네일 안정성 수정을 포함한 패치 릴리즈입니다.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • rhwp v0.8.2를 반영해 복잡한 표·페이지 배치, 오래된 HWP 그림과 테두리 표시를 보강했습니다.
  • 편집 뒤 저장할 때 문서 서식을 보존하는 범위와 편집기의 입력 반응성·실행취소 동작을 보강했습니다.
  • 창 너비가 바뀔 때 viewer/editor 상단 도구 모음과 서식 도구 모음이 겹치거나 잘리던 문제를 수정했습니다.
  • HOP과 알한글 Quick Look이 함께 설치된 검증 가능한 조합에서는 예상과 다른 미리보기가 선택될 수 있음을 알리고 확장 프로그램 설정 경로를 안내합니다.
  • 외부 연결 그림을 읽지 못해도 Quick Look 본문을 유지하고, 같은 그림을 처리하던 Finder 썸네일 확장이 종료될 수 있던 문제를 수정했습니다.

포함된 rhwp 변화

v0.1.9는 rhwp v0.8.2 기준의 core와 bundled rhwp-studio를 사용합니다. 앱 내부 provenance 기준 commit은 9b16aa9e23f476e2b335d7c029fc9f24a199d63c입니다.

  • 문단·다단·표의 저장된 배치 신호와 페이지 나눔을 더 충실하게 반영합니다.
  • HWP/HWPX 편집 뒤 저장할 때 표, 테두리, 그림과 문서 설정을 보존하는 범위를 넓혔습니다.
  • 바탕쪽의 머리말 개체, HWP 3.0 OLE/WMF 그림과 문단 테두리 표시를 보강했습니다.
  • rhwp-studio의 한글 입력 반응성, 실행취소 이력과 개체 선택 동작을 보강했습니다.
  • 인쇄 화면에 필요한 runtime asset과 누락 방지 build gate를 포함했습니다.

알한글 앱 변화

  • 앱 viewer/editor 화면은 bundled rhwp-studio v0.8.2를 사용하며, native core와 같은 release commit을 기준으로 합니다.
  • 앱 전용 WKWebView 표시 보정을 최신 반응형 레이아웃과 분리해 작은 창부터 넓은 창까지 툴바 높이와 항목 배치를 유지합니다.
  • 검증된 HOP Quick Look version이 알한글보다 오래된 rhwp를 포함하면 실행 안내와 About의 Quick Look 진단에서 버전 근거를 보여줍니다.
  • 알한글은 확장 프로그램 설정 화면만 열며 HOP이나 알한글 확장의 활성 상태를 자동으로 바꾸지 않습니다.
  • Quick Look은 안전한 sibling filename만 외부 연결 그림 후보로 사용하고, 누락·권한 거부·크기 초과를 문서 전체 실패와 분리합니다.
  • Rust 이미지 데이터를 안전한 소유 버퍼로 전달해 외부 그림이 포함된 문서의 Finder 썸네일 안정성을 보강했습니다.
  • 설치본 version/build 기준은 0.1.9 (15)입니다.

알려진 한계

  • Quick Look과 Finder 썸네일은 native 렌더 경로를 사용하고, 앱 화면은 WKWebView 기반 rhwp-studio 경로를 사용합니다.
  • 일부 문서에서는 글꼴, 배치, 페이지 표현이 원본 한글 프로그램과 다르게 보일 수 있습니다.
  • registered Quick Look sandbox가 sibling file 접근을 허용하지 않으면 외부 연결 그림은 빠지지만 문서 본문 미리보기는 유지됩니다.
  • Finder 썸네일과 앱 viewer/editor에서는 외부 연결 그림 표시를 보장하지 않습니다.
  • HOP 충돌 안내는 검증된 version metadata를 기준으로 하며 현재 활성 provider를 강제로 판정하거나 변경하지 않습니다.
  • HWPX 문서는 직접 저장이 제한되어 HWP 내보내기 경로를 사용합니다.

설치와 업데이트

DMG 파일을 내려받아 앱을 Applications 폴더로 옮긴 뒤, 앱을 한 번 실행합니다. v0.1.9 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew 사용자는 brew install --cask postmelee/tap/alhangeul로 같은 signed/notarized universal DMG를 설치할 수 있습니다.

설치한 앱에서는 메뉴 막대의 알한글 > 업데이트 확인...을 선택해 새 버전을 확인할 수 있습니다.
