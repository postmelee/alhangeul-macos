알한글 v0.2.0

한글 문서를 본문으로 찾고, 새 문서를 저장하고, Word·HTML로 내보내는 흐름을 개선했습니다.

아래에서 공식 DMG를 내려받거나 앱의 업데이트 확인 메뉴를 이용하세요.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • Spotlight에서 HWP/HWPX 문서를 파일명뿐 아니라 본문 단어로 찾을 수 있습니다.
  • 새 문서를 처음 저장할 때 잘못 나타나던 “저장할 문서가 없습니다” 오류를 수정했습니다.
  • Word·HTML 내보내기의 저장 창과 일부 문서의 미리보기 표시를 보완했습니다.

포함된 rhwp 변화

문서 처리 엔진과 편집 화면은 직전 버전과 같은 rhwp v0.8.6을 사용합니다. 이번 버전은 알한글의 검색·저장·내보내기 개선에 집중했습니다.

알한글 앱 변화

  • 앱을 설치하고 한 번 실행하면 기존 평문 HWP3/HWP5/HWPX 문서의 본문 검색을 준비합니다. 앱을 종료한 뒤에도 색인된 문서를 Spotlight로 찾을 수 있습니다.
  • 새 문서의 첫 저장과 이후 저장, 미저장 상태 및 닫기 동작을 보정했습니다.
  • Word(.doc)·HTML 내보내기에서 macOS 저장 창을 표시하고 원래 문서의 저장 위치와 편집 상태를 유지합니다.
  • 일부 문서에서 미리보기의 머리말·꼬리말 텍스트가 누락되는 경로를 보완했습니다.

알려진 한계

  • Spotlight 검색 결과는 macOS의 색인 상태와 검색 제외 설정에 영향을 받으며, 설치·수정·삭제가 반영되기까지 시간이 걸릴 수 있습니다.
  • 암호·DRM·배포용 문서, 이미지·스캔 OCR과 일부 문서 요소는 본문 검색 대상이 아닙니다. 큰 문서는 본문 뒤쪽이 검색되지 않을 수 있습니다.
  • 검색은 저장된 텍스트를 대상으로 하며 시각적 읽기 순서를 재현하거나 숨긴 본문을 제거하는 기능이 아닙니다.
  • Word 내보내기는 HTML 기반 .doc 파일입니다. 모든 Word 버전에서의 문서 배치를 보장하지 않습니다.
  • 암호 보호를 유지하는 저장과 HWP3 원형 저장은 지원하지 않습니다. 앱과 Finder 미리보기의 글꼴·배치는 다를 수 있습니다.

설치와 업데이트

DMG에서 앱을 Applications 폴더로 옮기고 한 번 실행하세요. macOS 12 이상, Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

설치한 앱에서는 알한글 > 업데이트 확인... 메뉴로 새 버전을 확인할 수 있습니다. Homebrew 반영 전에는 위 DMG를 직접 설치하세요.
