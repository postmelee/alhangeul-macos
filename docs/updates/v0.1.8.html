알한글 v0.1.8

rhwp v0.7.18 문서 처리·편집 개선과 HOP HWP/HWPX 문서 형식 호환을 포함한 패치 릴리즈입니다.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • rhwp v0.7.18을 반영해 복잡한 표·도형·페이지 배치의 문서 호환성과 큰 표 처리 성능을 보강했습니다.
  • bundled 편집기의 입력, 실행취소, 후반 페이지 조작과 표 셀 편집 동작을 보강했습니다.
  • HOP이 등록한 HWP/HWPX 문서 형식도 알한글의 호환 형식으로 인식해 Finder의 다음으로 열기와 기본 앱 후보에서 알한글을 선택할 수 있는 경로를 보강했습니다.
  • 웹사이트에 이메일과 GitHub Issue를 이용할 수 있는 문의/제보 페이지를 추가했습니다.
  • 공식 DMG는 Intel Mac과 Apple Silicon Mac을 모두 지원하는 signed/notarized universal DMG입니다.

포함된 rhwp 변화

v0.1.8은 rhwp v0.7.18 기준의 core와 bundled rhwp-studio를 사용합니다. 앱 내부 provenance 기준 commit은 93862a4e16df59834ebce46d91e948cd739208e9입니다.

  • 부동·전면 개체, 여러 페이지에 걸친 표, 저장된 개체 크기와 글꼴 폭을 다루는 문서 배치 처리가 보강되었습니다.
  • 초대형 표와 큰 셀을 포함한 문서의 처리 성능이 개선되었습니다.
  • rhwp-studio에서 후반 페이지 입력, 실행취소, OLE 개체와 표 셀 Enter/IME 동작이 보강되었습니다.
  • 일부 손상·보호 문서의 판별과 HWPX 원본 보존 처리가 보강되었습니다.

알한글 앱 변화

  • 앱 viewer/editor 화면은 bundled rhwp-studio v0.7.18을 사용하며, upstream 문서 처리와 편집 보강을 같은 버전 기준으로 반영합니다.
  • HOP이 등록하는 HWP/HWPX 문서 타입을 HostApp, Quick Look preview, Finder thumbnail과 앱 내부 열기 패널의 호환 형식에 추가했습니다.
  • 이번 변경은 사용자가 Finder에서 알한글을 선택할 수 있는 경로를 보강하며, macOS 기본 앱을 자동으로 변경하지 않습니다.
  • About 창에서 bundled rhwp v0.7.18 기준을 확인할 수 있습니다.
  • 설치본은 0.1.8 (14) signed/notarized universal DMG로 배포됩니다.

알려진 한계

  • Quick Look과 Finder 썸네일은 native 렌더 경로를 사용하고, 앱 화면은 WKWebView 기반 rhwp-studio 경로를 사용합니다.
  • 일부 문서에서는 글꼴, 배치, 페이지 표현이 원본 한글 프로그램과 다르게 보일 수 있습니다.
  • HWPX 문서는 직접 저장이 제한되어 HWP 내보내기 경로를 사용합니다.
  • 외부 파일로 연결된 이미지는 아직 자동으로 찾아 표시하지 않습니다.
  • Finder 후보 표시는 LaunchServices 상태와 함께 설치된 앱에 따라 달라질 수 있습니다.

설치와 업데이트

DMG 파일을 내려받아 앱을 Applications 폴더로 옮긴 뒤, 앱을 한 번 실행합니다. v0.1.8 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew Cask 반영은 별도 배포 단계에서 진행합니다. 반영 전에는 GitHub Release의 DMG를 직접 내려받아 설치하세요.

설치한 앱에서는 메뉴 막대의 알한글 > 업데이트 확인...을 선택해 새 버전을 확인할 수 있습니다.
