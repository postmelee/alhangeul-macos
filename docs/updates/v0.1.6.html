알한글 v0.1.6

rhwp v0.7.16 문서 처리 개선과 HWPX 저장 계약·한컴 호환·다크 테마 보강을 포함한 패치 릴리즈입니다.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

  • rhwp v0.7.16을 반영해 HWPX 저장/내보내기에서 셀, 글상자, 캡션, 여백, 단 설정, 그림 크기, 메모, 표 page break 보존을 보강했습니다.
  • 누름틀 안내문이 한컴 에디터와 더 잘 호환되도록 upstream 문서 처리 기준을 갱신했습니다.
  • bundled viewer/editor에는 다크 테마, 누름틀 편집, 개체 비율 유지와 크기 고정, 표 안 그림 정렬 관련 보강이 포함됩니다.
  • Finder 썸네일 내부 cache가 renderer backend와 core provenance 차이를 구분하도록 보강되어, renderer 옵션 변경 뒤 오래된 thumbnail 재사용 위험을 줄였습니다.
  • 공식 DMG는 Intel Mac과 Apple Silicon Mac을 모두 지원하는 signed/notarized universal DMG입니다.

포함된 rhwp 변화

v0.1.6은 rhwp v0.7.16 기준의 core와 bundled rhwp-studio를 사용합니다. 앱 내부 provenance 기준 commit은 de02159ab4d2c5d165d6e25568bad3f8af5ef6cb입니다.

  • HWPX 저장 계약 보존 범위가 넓어져 셀, 글상자 컨트롤, lineseg, 캡션, 문단/구역 속성, 그림과 표 관련 속성의 라운드트립 정합성이 보강됩니다.
  • 누름틀 안내문 command 포맷이 한컴 에디터와 더 잘 맞도록 정정됩니다.
  • rhwp-studio에는 다크 테마, 누름틀 편집, 개체 크기/비율, 표 안 그림 정렬, 로컬 파일 drag/drop 보안 확인 경로가 포함됩니다.
  • 렌더링과 PDF export API, 미주 높이, 회전 셀 그림 배치 관련 upstream 보강이 포함됩니다.

알한글 앱 변화

  • 앱 viewer/editor 화면은 bundled rhwp-studio v0.7.16을 사용하며, upstream 문서 처리와 UI 보강을 같은 버전 기준으로 반영합니다.
  • Finder 썸네일 cache는 renderer option과 core provenance가 달라진 결과를 같은 cache 결과로 섞지 않도록 보강됐습니다. 기본 Finder 썸네일 renderer 정책은 그대로 유지됩니다.
  • About 창에서 bundled rhwp v0.7.16 기준을 확인할 수 있습니다.
  • 설치본은 0.1.6 (12) signed/notarized universal DMG로 배포됩니다.

알려진 한계

  • Quick Look과 Finder 썸네일은 native 렌더 경로를 사용하고, 앱 화면은 WKWebView 기반 rhwp-studio 경로를 사용합니다.
  • 일부 문서에서는 글꼴, 배치, 페이지 표현이 원본 한글 프로그램과 다르게 보일 수 있습니다.
  • HWPX 문서는 직접 저장이 제한되어 HWP 내보내기 경로를 사용합니다.
  • upstream rhwp-studio의 웹/확장 drag/drop 확인 UI는 bundled asset에 포함되지만, 알한글 macOS 앱의 Finder 열기와 앱 내부 파일 열기는 HostApp native document router 정책을 따릅니다.

설치와 업데이트

DMG 파일을 내려받아 앱을 Applications 폴더로 옮긴 뒤, 앱을 한 번 실행합니다. v0.1.6 공식 DMG는 Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

Homebrew Cask를 사용하는 경우 아래 명령으로 같은 signed/notarized universal DMG를 설치할 수 있습니다.

brew install --cask postmelee/tap/alhangeul

Homebrew가 untrusted tap 정책으로 설치를 거부하면 brew trust --cask postmelee/tap/alhangeul을 한 번 실행한 뒤 다시 설치하세요.

설치한 앱에서는 메뉴 막대의 알한글 > 업데이트 확인...을 선택해 새 버전을 확인할 수 있습니다.
