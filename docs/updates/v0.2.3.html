알한글 v0.2.3

Mac에 설치한 글꼴을 익숙한 글꼴 목록에서 선택하세요. 문서 화면과 PDF·인쇄, Finder 미리보기·썸네일에도 연결했습니다.

배포 상태와 공개일은 GitHub Release에서 확인하세요.

DMG 다운로드 GitHub Release 업데이트 목록

변경 요약

Mac 설치 글꼴 사용을 켜면 별도 선택 팝업 없이 기존 글꼴 목록에서 고를 수 있습니다. 지원 글꼴의 문서·출력 연결과 반복 Finder 요청의 글꼴 준비를 개선했습니다.

포함된 rhwp 변화

문서 처리 엔진과 편집 화면을 공식 rhwp v0.8.7로 갱신했습니다. 표 너비와 쪽 나눔, 문단 배치, 일부 HWP/HWPX 저장본 호환성과 편집 동작을 보완했습니다.

알한글 앱 변화

  • 설정(⌘ + ,) → 글꼴에서 Mac에 설치된 글꼴 사용을 켠 뒤, 문서의 기존 목록에서 시스템 글꼴을 고릅니다. 기본 설정은 꺼져 있습니다.
  • 원본과 읽기 권한이 유지되면 다음 실행에도 사용 설정이 유지됩니다. 매번 글꼴을 가져올 필요가 없습니다.
  • 지원 글꼴을 HWP/HWPX 저장·재열기, PDF·인쇄 및 Finder Quick Look·썸네일에 연결했습니다.
  • 반복 Finder 요청에서 준비한 글꼴 정보를 재사용하고, 여러 파일의 썸네일 요청이 겹쳤을 때 제한된 대기열로 처리합니다. 처음 준비할 때와 많은 파일을 열 때는 시간이 걸릴 수 있습니다.

Mac 글꼴 사용 안내에서 설정·선택·권한 문제 해결을 단계별로 확인하세요. 별도 파일을 보관하려면 설정의 보관한 글꼴 → 글꼴 가져오기…를 사용합니다.

알려진 한계

  • 설치 글꼴은 원본의 존재·활성 상태·읽기 권한에 의존합니다. 한컴 앱 내부 글꼴 자동 추출이나 한컴 제거 후 모든 글꼴 유지를 보장하지 않습니다.
  • 일반 TTF/OTF의 검증된 Regular/Bold를 중심으로 지원합니다. TTC 개별 글꼴, 가변 글꼴의 모든 축과 HFT 지원은 보장하지 않습니다. Windows의 한컴 글꼴 폴더·ZIP 가져오기는 별도 후속 기능입니다.
  • 출력용 글꼴을 준비하지 못하면 기본적으로 취소하고 안내합니다. 안내에서 대체 글꼴 출력을 선택하면 모양과 배치가 달라질 수 있습니다.
  • Spotlight 검색 결과는 macOS의 색인 상태와 검색 제외 설정에 영향을 받으며, 설치·수정·삭제가 반영되기까지 시간이 걸릴 수 있습니다.
  • 암호·DRM·배포용 문서, 이미지·스캔 OCR과 일부 문서 요소는 본문 검색 대상이 아닙니다. 큰 문서는 본문 뒤쪽이 검색되지 않을 수 있습니다.
  • “저장하지 않음”으로 닫은 문서가 다음 실행의 복구 목록에 남는 문제는 이번 패치에 포함되지 않았습니다.
  • 검색은 저장된 텍스트를 대상으로 하며 시각적 읽기 순서를 재현하거나 숨긴 본문을 제거하는 기능이 아닙니다.
  • Word 내보내기는 HTML 기반 .doc 파일입니다. 모든 Word 버전에서의 문서 배치를 보장하지 않습니다.
  • 암호 보호를 유지하는 저장과 HWP3 원형 저장은 지원하지 않습니다. 앱과 Finder 미리보기의 글꼴·배치는 다를 수 있습니다.

설치와 업데이트

DMG에서 앱을 Applications 폴더로 옮기고 한 번 실행하세요. macOS 12 이상, Intel Mac과 Apple Silicon Mac에서 같은 파일을 사용합니다.

최초 실행 후 검색 준비와 문서 색인에 시간이 걸릴 수 있으므로, 처음에는 앱을 켜 둔 채 잠시 기다려 주세요. 소요 시간은 Mac의 상태와 문서 수에 따라 달라집니다.

메뉴 막대에서 알한글 → 업데이트 확인…을 선택하세요.

Homebrew의 현재 제공 버전과 명령어는 Homebrew 설치·업데이트 안내에서 확인하세요.
